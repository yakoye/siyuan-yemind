## 问题与根因

1. 工具栏首次显示时主动跳过真实 DOM Range，并用可能已过期的 Quill 矩形定位；缩放根节点的视口坐标也没有还原到本地坐标。
2. Quill 短暂返回长度为 0 的光标选区时，会覆盖之前保存的非折叠选区，使视觉上仍选中的文字无法 Ctrl+X、Delete 或 Backspace。
3. HTML 编辑层与 SVG 节点同时绘制背景，节点预留的文字内边距会暴露为第二个错位白框。
4. 工具栏容器取消 `hidden` 后立即进入可绘制状态，但原生下拉控件和最终几何尚未提交，WebView2 会先绘制一帧空白外壳或旧位置，再跳到当前选区。
5. 从节点 A 切换到节点 B 时，即使 A 的文本未改变，关闭编辑仍执行 `SET_NODE_TEXT` 与整图重绘，使 A 的静态文字层在交接帧发生跳动。
6. 富文本中的普通链接点击沿用了浏览器默认导航；公式插入到代码块选区后还会遗留空代码块。
7. 退出编辑会先清空活动节点引用，而静态文字恢复逻辑先检查活动节点再恢复旧层；未修改节点因此可能保留 `visibility:hidden`，表现为空白节点。
8. 点击另一个静态节点时，鼠标按下虽然隐藏了旧工具栏，但鼠标抬起仍可能发布旧编辑会话排队的选区，形成旧位置空白外壳。

## 架构修复

- 活动 `.ql-editor` 或大纲编辑器中的非折叠 DOM Range 是工具栏定位的权威坐标源。
- 工具栏统一把视口坐标换算为根容器局部坐标，同时处理缩放比例。
- 新一轮鼠标选择开始时立即隐藏并失效旧工具栏；新工具栏先保持 `visibility:hidden`，在两个动画帧中完成控件布局、当前选区测量与边界约束，再一次性显示。
- 工具栏按既有产品约定优先贴近选区下方；下方空间不足时才翻转到上方，始终限制在当前编辑器可视区域内。
- 节点退出编辑时先比较规范化文本与 `richText` 标志；内容未变化则不执行 `SET_NODE_TEXT` 和整图重绘，只恢复既有 SVG 静态文字层。
- 静态文字恢复发生在活动节点守卫之前，即使退出事务已经清空活动节点引用，也能解除旧 SVG 文字层的隐藏状态。
- 静态节点上的新一轮点击丢弃旧编辑会话排队的选区；只有当前文字内拖选或新的编辑会话可以重新发布工具栏。
- 复制、剪切、Delete 和 Backspace 统一通过“当前非折叠选区，否则最后有效非折叠选区”的解析器。
- Ctrl+X 作为一次编辑事务完成写剪贴板、删除文字、折叠光标和清理工具栏状态。
- SVG 节点继续唯一负责边框与背景；HTML 编辑器只负责当前文字和光标。
- 普通链接点击保留给光标与选择事务，Ctrl/Cmd 点击才导航；行内公式写入前清除继承的代码块格式。

## 定向红绿证据

| 用例 | 修复前 | 修复后 |
|---|---|---|
| 活动 DOM Range 与陈旧 Quill 矩形相距较远 | 工具栏错误使用旧坐标 | 使用当前 DOM Range，工具栏间距正确 |
| 节点 A 工具栏可见时双击节点 B | 旧位置先闪空壳，再跳到 B | 鼠标按下即隐藏；首个可见帧已完整且位于 B 下方 |
| 从未修改的节点 A 切换到节点 B | A 仍执行文本命令和整图重绘，文字瞬间跳动 | A 不产生文本命令或整图重绘，静态层直接恢复 |
| 未修改节点退出编辑且活动节点引用已清空 | SVG 文字层未恢复，节点只剩空框 | 先恢复旧静态层，再检查是否仍有活动编辑节点 |
| 静态节点按下后收到旧会话延迟选区 | 鼠标抬起反显旧工具栏 | 丢弃旧会话事件，等待新会话完成测量后发布 |
| 实时 Quill Range 折叠、保存 Range 非折叠 | 剪贴板写入失败 | 使用保存选区完成复制/剪切 |
| 新建节点粘贴后的编辑层与 SVG | 出现第二个错位背景框 | HTML 背景透明，首帧几何与 SVG 对齐 |
