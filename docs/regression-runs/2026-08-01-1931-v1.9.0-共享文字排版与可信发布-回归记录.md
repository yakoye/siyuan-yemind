## 4. 焦点事务约束

- 编辑器结构就绪后开始打开焦点租约。
- 思源在同一编辑会话中程序化恢复 `RootWebArea` 时，按真实 `focusout` 重新声明 Quill 焦点，不猜测固定毫秒数。
- 用户发生真实 `pointerdown`、Quill 收到首个 `keydown`、窗口失焦、编辑关闭或会话中止时立即释放租约。
- 窗口 `blur` 只监听窗口自身事件，不使用捕获阶段误把元素 `blur` 当成应用切换。
