## 2. 确定性问题与根因

### 2.1 Tab/Enter/+ 新节点首帧空白

`openRealtimeRenderOnNodeTextEdit` 已关闭，但 YeMind 分支仍在 `TextEdit.show()` 中无条件隐藏静态 SVG 文字。新节点同步挂载后，Quill 虽已创建 DOM，但 Electron 可能尚未绘制首帧；此时静态层和编辑层没有可见字形，直到下一次画布交互才恢复。

修复前新增单元契约稳定失败：进入编辑后 `_textData.node.visible()` 为 `false`。本次把 `TextEdit.js` 完整恢复到上游 `wanglin2/mind-map` 提交 `e8e5ef9c41bc13ca7b13084e078123adff002242` 的原始实现。非实时模式保留静态 SVG 后备，由不透明 HTML 编辑层覆盖。

### 2.2 编辑提交时文字先偏左上再归位

`SET_NODE_TEXT` 会先同步 `node.reRender()`，再通过 `setTimeout(0)` 安排整图布局。旧代码在命令执行前就把 HTML 编辑层设为 `display:none`，因此浏览器可看到新静态文字处于临时局部原点的一帧，随后 `node_tree_render_end` 才归位。

修复前新增单元契约稳定失败：执行 `SET_NODE_TEXT` 时编辑层已经是 `display:none`。本次在内容发生变化时保留不透明编辑层，直到 `node_tree_render_end` 后再切换到最终 SVG；未变化时先恢复已布局的 SVG，再移除编辑层。切换使用渲染事件和会话修订号，不使用固定延时、额外动画帧或坐标补偿。

## 3. 架构收敛

- `vendor/simple-mind-map-runtime/src/core/render/TextEdit.js` 已与上游原文件字节一致，并从 `UPSTREAM_BASELINE.json` 的允许修改列表删除。
- vendored runtime 的差异减少为 `KeyCommand.js`、`nodeModifyWidth.js`、`RichText.js` 三个有明确回归依据的文件。
- 静态 SVG 是非实时编辑模式的后备层；HTML 编辑器是不透明前景层；提交时前景层保持到最终布局完成，避免零可见层和临时几何暴露。
- 没有修改节点数据格式、宽度拖动实现、布局算法或保存格式。

## 4. 新增硬门禁

- 单元契约：非实时编辑打开后静态 SVG 必须仍可用。
- 单元契约：`SET_NODE_TEXT` 执行时不透明编辑层必须仍可见，`node_tree_render_end` 后才隐藏。
- E2E：Tab、Enter、+ 分别从新 SVG 节点首次挂载开始逐帧检查，每个可见帧必须有“新节点”静态字形或编辑字形。
- E2E：不再用节点数组最后一项猜测新节点，而是比较插入前后的真实 DOM 元素集合。
- E2E：新静态文字首次进入 DOM 时，旧的不透明编辑层必须仍在覆盖。
- E2E：节点切换时区分 DOM 后备层与视觉前景层；两层同时存在时必须验证前景编辑器为不透明实体层。
