## 2. 问题与根因

用户在思源实机中观察到：每次双击节点、切换编辑节点或删除节点时，导图会短暂跳到左上角，再回到原位置。性能 Trace 的调用链为：

```text
showEditText
→ focus
→ Quill setSelection
→ scrollSelectionIntoView
→ scrollRectIntoView
```

YeMind v1.9.0 把上游固定定位编辑器挂载在 `.ymz-editor` 内部；该容器同时承担导图视口并设置 `overflow: hidden`。Quill 聚焦光标时执行原生选区滚动，因而会短暂改变本地视口。删除旧编辑节点、切换新编辑节点也经过同一路径。

本次删除这个本地覆盖，恢复 `wanglin2/mind-map` 默认的 `document.body` 固定定位门户。没有增加延时、坐标补偿、轮询或另一套编辑生命周期。
