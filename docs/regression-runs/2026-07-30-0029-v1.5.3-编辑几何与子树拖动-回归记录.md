## 根因与实现边界

1. 活跃 Quill 编辑器期间，全树 `render` 会替换当前 SVG 节点；编辑器随后又绑定到新节点，形成文字右移、回跳和边框滞后。本版在编辑期间仅提交当前节点的测量、布局、节点更新和连线更新，结束编辑后仍走标准全树事务。
2. 打开编辑器后持续逐帧读取 SVG 矩形，会把过渡帧当作稳定几何。本版保留缩放、平移和容器尺寸变化的事件驱动重定位，删除无条件连续 RAF 监视。
3. 宽度手柄拖动使用上游实时草稿宽度；几何修复若在拖动中触发全树渲染，会把未提交宽度覆盖。本版在存在活动宽度拖动时禁止几何修复。
4. 上游结构拖动只克隆父节点并隐藏子级。本版仅克隆可见子树和内部连接线作为一个预览组，真实树仍由上游命令在松开时一次提交。
5. 多行选区的第一次 Delete/Backspace 曾先被画布快捷键层消费。本版由活跃 Quill 编辑器优先按真实非空选区执行一次删除。

## 定向验收

- [x] 双击多行节点后连续 6 帧编辑器位置和尺寸偏差不超过 1px。
- [x] 输入或粘贴后一帧内编辑器、SVG 节点边框和连接线使用同一实时几何。
- [x] 宽度手柄连续拖动时节点宽度单调变化，节点不消失、不跳到其他位置。
- [x] 拖动带子级的父节点时，预览同时包含可见父节点、子节点和内部连接线。
- [x] 多行文字选中后，Delete 和 Backspace 均一次清空真实选区。
- [x] `+`、`-`、数字保留 15px 视觉圆点，指针热区扩大到 28×26px。
- [x] 大纲多行节点的三角和叶子方块固定在第一行位置。
