## 根因与架构修复

1. 导图、大纲、右键菜单和键盘复制分别推断复制对象，旧节点载荷可能在真实文字复制后残留，导致后续粘贴错误变成整节点。
2. 图片选择、文字选区和节点选择缺少统一优先级；直接右击图片时旧选区可能抢占复制动作。
3. simple-mind-map 的延迟历史写入无法在立即撤销前可靠提交；历史回放触发的异步渲染回调还可能新建历史并截断重做分支。
4. 原有测试分散验证单个入口，没有把编辑态/非编辑态、导图/大纲、同文件/跨文件、新建节点前后组合成完整矩阵。
5. 富文本编辑层曾同时使用“目标 SVG 几何”和“上一次已绘制 HTML 几何”反向修正坐标，形成反馈回路；这会造成双击首帧闪动、节点切换重影、粘贴后边框滞后和宽度拖动抖动。
6. Tab/Enter 插入依赖上游延迟选中结果，宿主快捷键或结构重绘可能先夺走焦点，导致新节点已存在但编辑文字直到下一次点击才显示。
7. 单元测试曾遗留 `requestAnimationFrame` spy，使后续图片控件定位循环受到前序用例污染；全套运行与单文件运行结果不一致。

对应修复：

- 由统一复制意图决策层按“直接右击资源 → 真实文字选区 → 已选资源 → 节点结构”选择载荷。
- 图片剪贴板同时写入可用的二进制图片、安全 HTML、纯文本后备和 YeMind 资源元数据。
- 节点结构使用同一版本化载荷跨导图与大纲传递；跨文件过滤源 UID 与整节点展示样式。
- 历史协调器增加显式回放事务；从 BACK/FORWARD 开始到渲染结束期间拒绝新增历史，保证撤销/重做分支不被异步回调覆盖。
- 编辑层坐标只从当前 SVG 目标和实际 containing block 单向计算，不再读取上一帧 HTML 位置参与下一帧定位；编辑层在几何和内容同时就绪前保持不可见。
- Tab/Enter 预分配节点 UID，由统一插入协调器在结构完成后认领同一节点并恢复编辑焦点，阻断宿主重复快捷键。
- 测试基础设施在每个用例后恢复 spy 和全局 stub；需要同步动画帧的用例必须显式声明自己的时钟。
- 新建日常操作和剪贴板真实浏览器矩阵，逐帧检查编辑层、节点边框、工具栏、宽度拖动和快捷控件。
