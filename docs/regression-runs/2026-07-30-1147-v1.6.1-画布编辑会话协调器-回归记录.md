## 根因

1. 普通文本节点的静态文字位于完整 SVG 文本组，旧逻辑只隐藏富文本内部包裹层，因此普通多行节点会与 Quill 同时绘制。
2. 静态层可以在编辑器几何和内容准备完成前被隐藏，造成 60fps 捕捉到空白编辑框。
3. 工具栏先显示后定位，并可能读取上一节点仍在 DOM 中的 Range，造成旧位置出现、消失、再跳到当前节点。
4. 活动 UID、几何准备、内容准备和选区没有共同的会话编号，旧异步回调无法被一致拒绝。

## 架构修复

- 新增 `CanvasEditSessionCoordinator`，提供单调 `sessionId`、阶段、修订和选区纪元。
- SVG 静态文字仅在当前会话几何与内容均就绪后交接给 Quill。
- 普通文本隐藏完整 SVG 文字组，富文本隐藏对应富文本层；退出编辑恢复原有 visibility 与 aria 状态。
- 工具栏隐藏定位后一次显示；旧会话和远离当前矩形的 DOM Range 不参与定位。
- 节点切换后旧 Quill、旧选区和旧动画帧不能提交。
