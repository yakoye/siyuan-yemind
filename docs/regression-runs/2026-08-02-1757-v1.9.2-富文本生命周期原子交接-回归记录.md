## 2. Trace 证据与根因

输入证据：

- `Trace-20260802T171111.json.gz`
- `Trace-20260802T171727.json.gz`

两份 Trace 均运行 `v1.9.2`、`184345d0-clean` 构建。根因不是旧版逐字符实时 SVG 重建，而是编辑生命周期本身：

1. `TextEdit.show()` 在 Quill 编辑层创建前隐藏静态 SVG 文字，存在两层文字都不可见的同步空档。
2. `RichText.hideEditText()` 在内容未修改时仍执行 `SET_NODE_TEXT`、节点 `group.clear()` 和布局渲染。
3. 初始 `setSelection` 使用 Quill 默认滚动行为，调用 `scrollSelectionIntoView`，会干扰思源宿主视口。
4. 关闭修改内容时，`SET_NODE_TEXT` 已负责必要的节点重绘，随后额外的 `mindMap.render()` 属于重复整图渲染。

## 3. 最小内核差异

- `TextEdit.js`：编辑器完成内容、几何和焦点初始化后才隐藏静态文字。
- `RichText.js`：保存会话初始 HTML；未修改关闭时只恢复静态层，不发命令、不重建节点；修改关闭只保留一次必要提交；焦点使用 `preventScroll` 与静默选区。
- 没有新增 Coordinator、延时、轮询、坐标补偿或第二套渲染生命周期。
- `UPSTREAM_BASELINE.json` 只放行上述两个 Trace 已证明的文件，并由兼容性测试锁定精确清单。
