# YeMind v1.1.0 布局与大纲交互设计

## 目标

v1.1.0 解决两类长期问题：

1. “导图结构”中的 28 个预设不再只是少量上游布局的近似映射，实际结构、预览图、拖拽方向和节点快捷控件保持一致。
2. 大纲视图去掉无意义的左侧留白，为拖动热区提供可见的六点手柄，并统一图片、剪贴图和图标的选中与资源操作。

## 布局架构

新增一份布局几何元数据，作为以下功能的唯一依据：

- 预设顺序和标题；
- 实际布局类；
- 根节点、普通节点和叶子节点的生长方向；
- 同级节点排列轴；
- `+ / − / 数字` 快捷控件锚点；
- 拖拽候选区、插入指示线和房间预览；
- 预览缩略图。

每个预设使用独立的布局标识。原生布局继续复用上游 `simple-mind-map`，镜像和上下反转结构使用几何变换布局，双向、环形、气泡、树形表格等结构使用 YeMind 自有布局类。节点文字和图片始终保持正向，只变换节点坐标和连线路径。

导图结构首组顺序固定为：

1. 右向导图
2. 左向导图
3. 思维导图
4. 逆向导图
5. 双向平衡向下

## 节点快捷控件

`+ / − / 数字` 属于“从当前节点通向下级节点的出口”，定位规则如下：

1. 有已渲染子节点时，按当前节点到各直接子节点的主方向判定；
2. 双向结构按当前分支方向分别判定，根节点使用预设的根出口；
3. 折叠节点或叶子节点没有可测量子节点时，读取布局元数据的回退方向；
4. 布局切换后清除旧方向缓存，避免沿用上一个结构的锚点；
5. 控件沿对应边的中心对齐，并向外留出一致间距。

根节点、中间节点、折叠节点和叶子节点都进入自动化测试矩阵。

## 大纲布局与拖动

- 大纲独立视图的水平内边距固定为 8px，不再使用最高 96px 的展示型留白。
- 行首拖动列由 22px 收紧为 16px。
- 拖动列使用 2×3 六点手柄；默认低对比度，悬停、当前行和拖动时增强。
- 可拖动行使用十字 `move` 光标，拖动过程中切换为 `grabbing`。
- 缩进线、展开符号、拖动手柄和放置指示线继续共用同一组 CSS 几何变量。

## 图片、剪贴图和图标操作

- “替换”使用图片框加循环箭头的线性图标。
- “删除”使用简洁垃圾桶图标。
- 导图图片工具栏和共享资源操作浮层使用同一套 SVG 图标、尺寸、悬停和危险色规则。
- 大纲中的图片或剪贴图单击后立即出现蓝色选中框、八个控制点和右上角删除按钮。
- 大纲缩略图的八点只表示选中状态，不直接缩放；实际图片尺寸仍在导图画布中调整。
- `Delete` / `Backspace` 在媒体选中且不处于文本编辑时删除媒体。
- 单击选中与双击预览继续使用 380ms 仲裁窗口；资源替换浮层不会清除选中框。
- 点击其他节点、文本编辑区、空白处或按 `Escape` 清除媒体选中。

## 兼容与错误处理

- 旧文档只保存上游布局名时，通过兼容映射恢复到对应新预设。
- 未知布局回退到“右向导图”。
- 只读模式不显示删除、替换和拖动操作。
- 资源删除失败时保留选中状态，不留下半更新的大纲投影。
- 所有布局仍保留上游数据结构、历史记录、导入导出和撤销重做协议。

## 验证

- 单元测试覆盖 28 个预设映射、方向、顺序和快捷控件锚点。
- 几何测试覆盖镜像、上下反转、双向、环形和表格结构。
- 大纲测试覆盖紧凑边距、六点手柄、八点媒体选中、删除键和资源浮层图标。
- 浏览器回归生成布局总览截图，并分别验证插件版和网页版。
- 构建后同步到思源运行目录，再执行运行目录清单与版本一致性检查。
