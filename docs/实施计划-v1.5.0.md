# YeMind v1.5.0 实施计划

## 工作切片

1. **基线与隔离**：从 `origin/main` 建立独立工作树，安装锁定依赖，修复 CRLF 测试夹具并确认基线。
2. **统一外壳**：实现 version47 色彩、点阵画布、顶/底/左工具栏、统一隐藏提示、禅模式和编辑器宽度响应。
3. **面板与菜单**：对齐结构、主题、样式、搜索、导入导出、右键菜单和大纲侧栏；补齐键盘与触摸路径。
4. **内容交互**：回归导图/大纲增删改查、拖动、折叠、富文本选区、资源八点选择、替换/删除和图片预览。
5. **卡片与复习**：增加独立卡片数据、侧栏/全屏界面、筛选、翻面、状态、复习队列和持久化。
6. **传输与双端**：修正 v1.5.0 后缀，增加交互导图 HTML，保留旧格式兼容，确保两端调用同一实现。
7. **验证与发布**：更新 1.5.0 版本标记、README/CHANGELOG/测试文档，执行全量门禁、运行目录验证、GitHub 推送、Pages 和 Release 验证。

## 完成标准

- 清单中每项均有真实实现或已有回归证据，不保留无动作按钮。
- 类型、核心、网页、离线、资源、真实浏览器和发布包验证全部通过。
- 浅色、深色、桌面和 390px 窄屏可读，无横向工具栏滚动。
- 插件运行目录保留用户 `data/`，版本、构建和源码一致。
- GitHub Pages 与 Release 来自最终提交，页面能建图、保存、切换视图和打开导入导出。
