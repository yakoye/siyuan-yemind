# 版本管理

YeMind 使用语义化版本。当前稳定整理基线为 `1.1.1`。

## 版本号位置

发布时以下位置必须完全一致：

- `package.json`
- `package-lock.json` 根版本和根包版本
- `plugin.json`
- 根目录 `VERSION`
- `web/VERSION`
- `src/plugin/constants.ts` 中的 `PLUGIN_VERSION`
- `src/releaseInfo.ts` 中的 `buildId`

运行：

```text
npm run check:version
```

任何一处不一致都会失败。插件构建、网页版构建和 GitHub Pages 工作流都会执行该检查。

## 递增规则

- 修复错误且保持兼容：增加补丁版本，例如 `1.0.0` → `1.0.1`。
- 新增兼容功能：增加次版本，例如 `1.0.1` → `1.1.0`。
- 出现不兼容的数据、接口或使用方式变化：增加主版本，例如 `1.x` → `2.0.0`。
- 每次发布同步更新 `CHANGELOG.md`、中英文 README 和验证记录。
