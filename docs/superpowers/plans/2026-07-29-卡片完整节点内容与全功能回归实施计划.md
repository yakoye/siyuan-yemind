# YeMind 卡片完整节点内容与全功能回归 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让卡片保存并展示完整节点来源快照，并对 YeMind 插件版和网页版执行一次完整可复现回归。

**Architecture:** 保留现有 `front/back` 兼容层，新增独立、可规范化的 `StudyCardSourceSnapshot`。节点采集、持久化规范化和安全 HTML 呈现分离；卡片管理与复习共用呈现函数，来源更新只刷新快照。

**Tech Stack:** TypeScript、Vitest、JSDOM、Playwright Chromium、Vite、SiYuan 3.7.3。
