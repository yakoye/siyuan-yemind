# YeMind v0.9.26 Import Geometry, Collapse Semantics, and Outline Parity Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Every user-reported defect starts with a failing regression test.

**Goal:** Repair imported long-node geometry, make branch/global collapse deterministic, add outline image edit/preview interactions, and expose the same node-content actions in outline and canvas menus.

**Architecture:** Keep import-data repair and collapse state changes as pure tree transforms. The command adapter applies those transforms atomically through the existing map command bridge. The structured outline remains a content projection: it invokes existing canvas dialogs/commands for node-level content, while rich-text actions target the outline editor itself. Image interaction is delegated from the outline controller and routed by `YeMindEditor` to the shared image dialog and lightbox.

**Tech Stack:** TypeScript, DOM APIs, SiYuan Menu/Dialog, simple-mind-map, Vitest, dependency-free offline smoke tests, Chromium smoke tests, Vite/offline bundle builder.
