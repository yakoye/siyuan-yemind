# YeMind 基础编辑事务与剪贴板重构实施计划

> 版本：v1.5.0  
> 范围：网页端与思源插件共享代码  
> 原则：大纲首先是一套可靠的文本编辑器，文本编辑与节点结构编辑分层处理。

## 目标

解决以下基础编辑问题，并以自动化测试和真实浏览器回归约束后续修改：

1. 大纲输入空格、普通文字或清空时，导图节点不得因整树重建而异常缩放或跳动。
2. 导图节点进入编辑、编辑中、提交后采用一致的内容归一化和尺寸测量；空节点使用稳定的最小尺寸。
3. 普通网页段落粘贴到大纲时不产生软换行和空白节点；真正的缩进大纲仍按层级导入。
4. 导图选中文字可以复制，保留纯文本与富文本剪贴板内容。
5. 大纲选中文字后，Delete/Backspace 与普通文本编辑器一致。
6. 去除节点选择态的额外“阴影边框”，去除选中文字工具栏的整块背景。

## 根因与分层

### 文本事务

适用：单节点输入、选区删除、行内粘贴、行内格式、输入法提交。

- 根据稳定 UID 更新节点文本和富文本标记。
- 保留实时节点实例、当前画布变换、选区与兄弟结构。
- 只重新测量受影响节点并执行一次布局。
- 空白内容统一归一化为空字符串，不把占位 `<br>`、零宽字符或仅空格内容保存为节点正文。

### 结构事务

适用：Enter 新建节点、Tab/Shift+Tab 调整层级、跨节点删除、结构化多行粘贴、拖动排序。

- 构造并提交完整树事务。
- 保留已有 UID 和节点附件数据。
- 结构变化后恢复正确选区，不自动执行适配画布。

### 剪贴板事务

- 优先使用 `text/html` 的真实块结构识别段落。
- 普通段落中的浏览器软换行和空白分隔行合并为空格。
- 只有明确缩进、列表层级或 YeMind 自有结构标记才创建多节点结构。
- 导图富文本复制优先读取编辑器选区；无有效编辑器选区时才交还浏览器默认行为。

## 实施步骤

### 1. 建立失败测试

- 大纲单节点输入只触发文本事务，不调用整树替换。
- 空格、普通文字、清空三种输入保存值与节点测量稳定。
- 普通网页段落粘贴为一个节点；明确缩进文本仍生成层级节点。
- 导图富文本选区复制同时写入 `text/plain` 与 `text/html`。
- 大纲选区在工具栏交互后仍可用 Delete/Backspace 删除。
- CSS 合同保证无节点阴影和无浮动工具栏整块背景。

### 2. 重构大纲提交链路

- 为 `StructuredOutlineEditorController` 的 `onApply` 增加事务类型和变更集合。
- 比较提交前后块集合；仅文本变化时发送 UID 文本补丁。
- `YeMindEditor` 将文本补丁映射到命令层的节点文本更新；结构变化继续使用 `replaceTree()`。
- 输入法期间不提交，组合结束只提交一次。

### 3. 统一文本和空节点归一化

- 建立共享的语义空白判断与纯文本归一化函数。
- 编辑态、静态态和大纲态统一使用归一化结果。
- 删除仅空格内容后保存空字符串，空节点保持统一最小尺寸。
- 禁止文本提交触发自动适配或画布缩放。

### 4. 重构剪贴板和选区

- 增加 HTML 感知的粘贴分类器。
- 修复导图富文本复制的选区来源和空剪贴板问题。
- 大纲 Delete/Backspace 优先恢复已保存有效选区，再执行原生语义等价的删除。
- 保留结构化复制粘贴、只读复制和图片粘贴行为。

### 5. 统一视觉状态

- 移除节点激活态的填充/阴影式第二边框，仅保留清晰单线选择框。
- 富文本工具栏容器改为透明、无边框、无阴影；按钮自身保留 hover/active 状态。
- 明暗主题下检查文字和按钮对比度。

### 6. 验证与发布

- 运行相关 Vitest 套件、TypeScript 检查、网页测试、E2E 和离线测试。
- 在真实网页中操作：输入、清空、复制、粘贴、Delete、Enter、Tab、撤销/重做、明暗主题。
- 构建网页端和思源插件并同步运行目录。
- 验证思源运行目录与构建产物哈希一致。
- 更新开发测试与验收文档，提交并推送 GitHub；验证 GitHub Pages。

## 验收标准

- 编辑同一段文字时，进入编辑与退出编辑的节点外框尺寸差不超过 1px。
- 输入或清空单个大纲节点不会替换整棵树，不改变画布缩放和中心位置。
- 空节点可继续输入，外框不塌缩为零宽，也不残留空格节点。
- 普通段落粘贴不产生意外空节点；显式层级粘贴结果正确。
- 导图和大纲中的文本选区均可复制、删除和格式化。
- 所有新回归测试通过，原有测试无新增失败。
