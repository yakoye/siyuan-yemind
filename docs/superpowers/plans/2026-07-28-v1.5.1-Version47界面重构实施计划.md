# YeMind v1.5.1 Version47 界面重构实施计划

> 需求基线：`docs/YeMind_v1.5.0界面对齐勾选清单.txt`、用户 2026-07-28 提供的 21 张问题截图、
> `Improve Mind Map Design_version47.zip`。

## 一、执行规则

- 在 `feature/yemind-v1.5.1-refactor` 隔离工作树开发。
- 每个行为先写失败测试，再写最小实现，再重构。
- 每完成一个任务运行对应测试域；阶段结束运行完整测试。
- 不修改用户未跟踪的 `docs/YeMind_v2.0.0界面对齐勾选清单.txt`。
- 不用追加高优先级 CSS 覆盖掩盖旧规则；应删除或合并冲突规则。
- 视觉验收必须同时覆盖浅色和深色。
