# YeMind v0.9.27 Outline Assets and Dialog Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Every user-reported defect starts with a failing regression test.

**Goal:** Make outline asset interactions match the canvas, standardize asset and note dialogs, repair todo geometry, and keep accessory content synchronized across map, outline, and split views.

**Architecture:** Keep the structured outline as a projection of the same node data used by the canvas. Accessory clicks delegate through `StructuredOutlineEditorController` into the existing marker, clipart, image, note, comment, tag, link, and outer-frame commands. Marker rendering uses the same sprite-background contract as the canvas picker, and dirty outline text no longer blocks accessory-only synchronization. Asset dialogs share a compact custom header and anchor-aware placement so they never obscure the clicked node.

**Tech Stack:** TypeScript, DOM APIs, SiYuan Dialog, simple-mind-map, Vitest, dependency-free offline smoke tests, Chromium smoke tests, Vite/offline bundle builder.
