# YeMind v0.9.29 Floating Toolbars, Relation Selection, and Quick Actions Plan

## Goal

Make view switching clear transient image editing state, make relation lines easy to select without changing their appearance, keep node quick actions attached to the actual child branch in every layout, and add practical floating-toolbar controls for pinning, direct zoom entry, and map renaming.

## TDD sequence

1. Add failing unit tests for direct-child counts, branch-side anchor placement, recursive collapse / one-level expand, relation hit width, zoom parsing, title normalization, and toolbar pin persistence.
2. Add failing DOM/browser-facing tests for editable zoom/title controls, pin button, auto-hide state attributes, view-switch image-selection cleanup, and shared outline image preview routing.
3. Implement the smallest pure helpers first.
4. Wire helpers into commands, relation plugin, image adjustment plugin, editor template, settings, tab title updates, and toolbar visibility controller.
5. Add CSS for non-layout relation hit paths and floating toolbar transitions.
6. Run targeted tests, offline smokes, syntax checks, bundle build, browser smoke, then full available regression suite.
7. Package deterministically, re-extract, and repeat release checks.

## Functional contract

- Leaving map view clears image/clipart resize handles and resource toolbars; node selection may remain.
- Relation visual stroke remains unchanged, while an invisible 12px stroke accepts pointer events.
- Relation SVG overlays never participate in node text/layout measurement.
- Quick-action number equals direct child count.
- Collapse recursively closes all descendants; expansion opens only the direct child layer.
- Quick actions anchor to the side of the node where direct children actually connect.
- Top and bottom toolbars auto-hide by default and reveal from edge/toolbar hover. One pin controls both and persists.
- Zoom accepts values such as `80`, `80%`, and clamps to configured limits.
- Clicking the bottom map title enables rename; Enter/blur saves, Escape cancels, blank names fall back to `未命名导图`.
- Outline image double-click invokes the same ImageLightbox instance as canvas preview.
