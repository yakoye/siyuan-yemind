# YeMind v0.9.30 Branch Controls, Toolbar States, and Resource Menus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Make branch quick controls follow the actual outgoing child connector in every layout, separate one-level expansion from full subtree/global expansion, default all floating toolbars to pinned, expose clear pin/lock states, and restore two-step replace/delete interaction for node icons and clipart.

**Architecture:** Add pure layout/expansion helpers first, then wire them into quick-action rendering and command/context-menu entry points. Keep toolbar state expressed through persisted settings plus explicit icon renderers, and reuse one resource action popover for canvas and outline marker/clipart interactions before opening the existing asset dialogs.

**Tech Stack:** TypeScript, simple-mind-map, SiYuan Menu/Dialog APIs, Vitest suites, dependency-free offline smoke entries, Chromium smoke scripts.
