# YeMind 卡片完整节点内容与全功能回归设计

## 1. 目标

卡片不再只复制节点标题和备注纯文本。创建卡片时保存一份可独立复习的节点来源快照，完整保留节点图片、剪贴图、图标、标号、待办、标签、链接、富文本、公式、备注和批注。随后对用户此前提出的导图、大纲、资源、搜索、主题样式、卡片复习、导入导出和双端发布能力执行完整回归。

## 2. 数据边界

`StudyCard.front` 与 `StudyCard.back` 继续作为用户可独立编辑的题面和答案，保证旧卡片兼容。新增可选的 `source`：

```ts
interface StudyCardSourceSnapshot {
  version: 1;
  capturedAt: number;
  nodeTextHtml: string;
  nodeTextPlain: string;
  icons: string[];
  tags: string[];
  todo: NodeTodo | null;
  hyperlink: string;
  hyperlinkTitle: string;
  image: {
    src: string;
    title: string;
    kind: 'image' | 'clipart';
    width?: number;
    height?: number;
  } | null;
  noteHtml: string;
  comments: NodeComment[];
}
```

旧数据没有 `source` 时继续按原来的纯文字卡片显示。规范化过程清理非法字段、限制数组数量并净化富文本，不修改现有复习调度字段。

## 3. 创建与更新语义

1. 从节点首次创建卡片时：
   - `front` 使用节点可读纯文本；
   - `back` 使用备注可读纯文本；
   - `source` 保存完整节点快照。
2. 已存在的卡片不因节点重绘或编辑而自动覆盖，防止用户自行编辑的题面和答案丢失。
3. 卡片编辑区增加“从来源节点更新”：
   - 只刷新 `source`；
   - 不覆盖 `front/back`；
   - 来源节点不存在时禁用，并显示“来源节点已删除”。
4. 删除节点后卡片和快照继续存在，可离线复习。

## 4. 卡片与复习呈现

- 卡片正面显示题面、节点图标/标号、待办、标签、图片或剪贴图。
- 卡片背面显示用户答案、备注富文本和批注列表；相同纯文本不重复展示。
- 图片使用现有统一灯箱预览，支持单击、缩放和关闭。
- 公式保留安全富文本结构；不允许脚本、事件属性或危险 URL。
- 复习界面使用与卡片管理界面相同的内容渲染器，避免两套展示逻辑漂移。
- 搜索范围扩展到题面、答案、节点文本、备注、批注、标签和图片说明。

## 5. 双端与传输

- `studyCards` 仍位于 `YeMindMapDocument`，插件和网页版共用实现。
- `.yemind.svg`、`.yemind.zip`、KMindz、XMind 元数据和网页备份继续携带完整 `studyCards`。
- Markdown、OPML、Text 等纯大纲格式不承诺保存卡片。
- 所有本地图片数据或资源 URL 原样保存；丢失资源显示占位和说明，不导致卡片面板崩溃。

## 6. 错误与安全

- 快照规范化拒绝空 ID、非法图片对象、超长列表和非有限尺寸。
- 所有富文本使用现有 `sanitizeRichHtml`。
- 图片加载失败显示替代文本，不能破坏翻面、复习评价和下一张卡片。
- 保存失败保持现有卡片数据并显示错误，不静默清空快照。

## 7. 验收

1. 含图片、剪贴图、图标、待办、标签、链接、公式、备注和两条批注的节点创建卡片后，上述内容均能在卡片与复习中看到。
2. 刷新、导出再导入后快照内容不丢。
3. 更新来源节点后，手动同步只更新快照，不覆盖用户编辑过的题面和答案。
4. 删除来源节点后仍可复习，并显示来源缺失状态。
5. 旧纯文字卡片加载、编辑、复习和调度结果不变。
6. 完整自动门禁、桌面和移动浏览器 E2E、思源冷启动实机回归均通过。
