# YeMind v1.5.0 Version47 界面重构设计

> 本轮正式发布版本为 `v1.5.0`。内部自动化中已存在的 `V151` 仅作为测试用例编号，不代表产品版本。

## 1. 背景与结论

v1.5.0 已发布，但实际界面与 `Improve Mind Map Design_version47.zip` 仍存在明显差距，且
`YeMind_v1.5.0界面对齐勾选清单.txt` 中部分已勾选项目没有形成可重复的验收证据。

本轮 v1.5.0 Version47 对齐采用以下不可变原则：

1. Version47 是视觉、排布、图标和交互节奏的唯一参考基线。
2. 保留当前 YeMind 的真实数据、导图引擎、导入导出、卡片、复习和思源集成能力。
3. 插件版与网页版继续复用同一套编辑器代码，只保留宿主适配层差异。
4. 不继续在 `src/styles/index.css` 尾部追加互相覆盖的临时规则。
5. 不能由局部修改稳定解决的问题，重构对应状态模型或生命周期。
6. 每个问题必须同时具备失败测试、实现、自动验证和必要的截图/人工证据，不能以文档勾选代替验收。

本版本统一使用版本号 `1.5.0`。

## 2. 目标

- Version47 的顶部栏、底部栏、左侧工具栏、缩略图、大纲、搜索和面板视觉可辨识地对齐。
- 浅色、深色、选中、高亮、禁用、悬停和键盘焦点状态都清晰可读。
- 新建、编辑、删除、拖动、折叠、展开和关系线更新不再出现一帧旧状态或几何漂移。
- 思源重启恢复标签后，同一导图只激活已有标签，不重复创建。
- 现有数据格式和 v1.5.0 文件无损兼容。
- 网页版与思源插件版从同一已验证提交产出。

## 3. 非目标

- 不整体迁移到 Version47 原型使用的 React、Tailwind 或组件库。
- 不用 Version47 的静态演示数据替换真实导图数据。
- 不在本轮重新设计卡片调度算法；只修复卡片/复习导航和统一图标。
- 不改变 `.yemind.svg`、`.yemind.zip` 等已经确认的文件格式名称。
- 不修改用户新建但未纳入本版本的 `docs/YeMind_v2.0.0界面对齐勾选清单.txt`。

## 4. 设计系统

### 4.1 语义变量

界面颜色只能通过语义变量使用，禁止组件直接依赖思源宿主的蓝色选中变量。

| 语义 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--ymz-page-bg` | `#eef0f5` | `#111318` | 画布外壳 |
| `--ymz-toolbar-bg` | `rgba(255,255,255,.97)` | `rgba(28,31,40,.97)` | 顶部、底部工具栏 |
| `--ymz-panel-bg` | `rgba(252,252,253,.98)` | `rgba(22,25,34,.98)` | 大纲、搜索、菜单 |
| `--ymz-input-bg` | 浅灰白 | `#252833` | 输入框 |
| `--ymz-accent` | `#22c9a0` | `#22c9a0` | 主动作和焦点 |
| `--ymz-selection-bg` | 低透明绿色 | 低透明绿色 | 行和文字选中 |
| `--ymz-text-100` | 深灰黑 | 近白 | 标题 |
| `--ymz-text-80` | 中深灰 | 高亮灰白 | 正文 |
| `--ymz-text-60` | 中灰 | 中亮灰 | 次要正文 |
| `--ymz-text-40` | 浅灰 | 暗亮灰 | 辅助文字 |

工具栏不使用投影阴影；弹出面板只保留一层轻阴影；右键菜单使用不透明表面、边框和分组分隔，
不使用毛玻璃，也不将每个菜单项画成独立卡片。

### 4.2 图标

建立单一图标注册表，约束为 16 或 18 像素、统一线宽、圆角端点和视觉盒子。

- 品牌图标恢复项目原有 YeMind 图标。
- “导图”恢复原有导图图标。
- 工具区无法确认时优先采用 Version47 同名图标。
- 浅色/深色图标统一通过 `currentColor` 着色，不维护两套不可见的 SVG。
- “跟随系统”采用半日半月或自动外观图标，不使用显示器图标。
- 全屏统一采用 Version47 的对角展开图标，大纲、卡片和其他面板共用。

## 5. 外壳与工具栏状态

### 5.1 单一状态机

顶部、左侧、底部工具栏仍共享固定/自动隐藏状态，但每条边保留独立的唤回感知：

```ts
interface ToolbarShellState {
  pinned: boolean;
  zen: boolean;
  interactionOwner: 'top' | 'left' | 'bottom' | 'panel' | null;
  visibility: Record<'top' | 'left' | 'bottom', 'shown' | 'hiding' | 'hidden' | 'revealing'>;
}
```

任一边缘被命中时三条工具栏一起进入 `revealing`，使用相同动画时长；输入框、菜单或对话框持有
`interactionOwner` 时禁止隐藏。减少动画模式下状态不变，只将过渡时长归零。

### 5.2 隐藏提示

- 顶部、底部提示是细线，左侧提示是细竖线。
- 颜色由当前表面色与强调色混合，浅色背景偏亮、深色背景偏暗，不能固定为纯绿色。
- 提示线默认低透明度，接近时提高透明度并平滑过渡。
- 提示线和外壳边界融合，不出现发光阴影、粗线或孤立的减号按钮。

### 5.3 工具栏排布

顶部遵循 Version47：

`品牌 | 导图 大纲 卡片 复习 | 结构 主题 样式 | 搜索 | 导入 导出 分享 | 外观 | 保存`

底部遵循 Version47：

`导图名称与统计 | 适配 选择/拖动 锁定 禅模式 固定 演示 | 缩小 百分比 放大 重置 | 缩略图 帮助`

窄窗口先隐藏文字，再收进“更多”，不改变核心图标顺序。

## 6. 缩略图与缩放

### 6.1 缩略图

缩略图不再直接相信引擎返回的内联宽高。新控制器分三层：

1. `MiniMapSnapshot`：从引擎取得 SVG、内容边界和当前视口。
2. `projectMiniMapSnapshot`：纯函数校验尺寸、统一 viewBox、计算缩放和视口矩形。
3. `MiniMapController`：节流渲染、拖动、点击定位和生命周期清理。

异常约束：

- 内容为空、宽高为零、非有限数或 SVG 不完整时保留上次有效快照。
- 视口矩形必须钳制在缩略图内部，最小可见尺寸 6px。
- 打开大纲/卡片后重新测量，不能把视口画成跨越整个卡片。
- 缩略图使用 Version47 的 160×100、圆角、标签和主题表面，不使用重阴影。

### 6.2 缩放

缩小、百分比、放大、重置的顺序和盒子移植 Version47。百分比是可编辑输入：

- 最小、最大和步进使用引擎真实约束。
- Enter 提交，Esc 恢复，失焦校验。
- 非数字、空值和越界值不会传入引擎。

## 7. 节点与渲染生命周期

### 7.1 根节点

根节点尺寸由主题配置表达，不用选择态 CSS 临时放大：

- 字号、内边距、最小宽高均大于同主题的普通节点。
- 图片根节点和富文本根节点仍保持文本居中。
- 结构转换后重新测量，不沿用旧节点边界。

### 7.2 原子刷新

新建节点空白、删除后文字偏移、关联线闪现的共同根因是多个插件在不同事件中读取不同帧的数据。
增加编辑器级刷新协调器：

```ts
type MutationKind =
  | 'insert'
  | 'edit'
  | 'remove'
  | 'move'
  | 'collapse'
  | 'layout'
  | 'resource';

interface RenderCommit {
  revision: number;
  kind: MutationKind;
  selectedUids: string[];
  dataReady: boolean;
  geometryReady: boolean;
}
```

一个操作只发布一次 `RenderCommit`。刷新顺序固定为：

1. 提交数据和富文本；
2. 引擎完成节点树渲染；
3. 更新节点尺寸和选区；
4. 更新快捷按钮、关联线、外框和图片控制点；
5. 更新大纲、搜索索引和缩略图；
6. 自动保存。

过期 revision 的回调必须丢弃。这样新节点文字不等待下一次选择，删除后不会把旧文本坐标应用到新节点，
拖动时无关关联线保持自己的可见状态和几何。

## 8. 大纲

大纲采用 Version47 的视觉，但保留当前跨父级拖动和富文本能力。

- 根和有子节点行使用彩色三角；叶子使用同分支颜色的小方块。
- 缩进线按行分段，每行上下各留小间隙；线、三角和方块由相同分支颜色函数产生。
- 对齐线基准统一减 1px，三角中心、叶子方块中心和缩进线 x 坐标共用一个几何函数。
- 当前行使用低透明 YeMind 绿色背景和高对比正文，不使用宿主蓝色。
- `::selection` 使用可读的绿色透明背景；深色模式不能把文字和背景同时染成绿色。
- 六点拖动仅在行左侧 gutter 接近、键盘聚焦或正在拖动时显示。
- 选中文字时，拖动命中和行选择不得抢走浏览器选区。
- 图片/剪贴图保持八点选择、替换、删除和灯箱预览。

## 9. 搜索与替换

搜索面板采用 Version47/VS Code 的两行结构，使用真实搜索结果：

```ts
interface SearchOptions {
  caseSensitive: boolean;
  wholeWord: boolean;
  useRegex: boolean;
  preserveCase: boolean;
  scope: 'document' | 'selection';
}

interface SearchMatch {
  uid: string;
  start: number;
  end: number;
  preview: string;
}
```

- 第一行：展开替换、查找输入、大小写、全字、正则、结果计数、上一个、下一个、关闭。
- 第二行：缩进、替换输入、保留大小写、替换当前、全部替换。
- 非法正则显示内联错误，不修改节点。
- 选项改变时重建结果；当前结果按 UID 和字符范围稳定定位。
- 搜索范围至少支持当前文档；多选存在时可选择选中节点。
- 面板在右边、底边钳制，不遮挡顶部主操作。

## 10. 菜单与面板

### 10.1 右键菜单

复用当前真实命令模型和防溢出定位，但重写展示层：

- 不透明表面；
- 单一连续列表；
- 组间细分隔线；
- 仅 hover/focus 行有背景；
- 图标、文字、快捷键三列对齐；
- 危险项只使用危险色，不做独立卡片；
- 子菜单可左右翻转并限制高度。

### 10.2 卡片与复习

“卡片”是管理、搜索、创建和编辑；“复习”是按队列学习。状态关系固定：

- 点击“卡片”选中卡片导航并打开卡片面板。
- 点击“复习”选中复习导航并打开复习中心/学习队列。
- 在复习中点击“查看卡片”退出学习视图、选中“卡片”、定位到对应卡片。
- 全屏按钮统一使用共享展开图标。

## 11. 思源标签去重

运行期注册表不足以识别思源重启后恢复的标签。改为两阶段去重：

1. `tabs.init` 一开始按 `mapId` 注册“恢复中”句柄，不等待编辑器可见。
2. `openMap` 在创建新标签前先查询注册表；若存在恢复中或已就绪句柄，激活它。

注册表允许句柄从 `restoring` 更新为 `ready`，但同一个 `mapId` 只能有一个主句柄。若宿主历史状态已经
恢复出重复标签，最先可见者成为主标签，其余标签只在确认已挂载且不含未保存本地状态时关闭。

## 13. 兼容与错误处理

- 非法正则、无效缩放和缩略图异常只影响当前操作，不破坏导图。
- 渲染 revision 超时记录诊断并触发一次安全全量刷新。
- 标签句柄失活时从注册表删除，再允许创建。
- 大纲装饰缺少主题色时回退到确定的六色分支色，而不是透明或宿主蓝色。
- 所有全局监听、动画帧、观察器在销毁时清理。

## 14. 发布门禁

以下条件同时成立才允许标记 v1.5.0 Version47 对齐完成：

1. 新增回归测试先失败后通过。
2. `npm test`、`npm run test:web`、`npm run check`、`npm run build:all` 全部通过。
3. 桌面五档宽度与浅/深主题截图完成视觉对比。
4. 节点 CRUD、拖动、关系线、大纲、搜索、卡片导航和标签去重主流程通过。
5. 插件运行目录由发布白名单同步，用户数据未删除。
6. 思源真实运行和公开 GitHub Pages 页面均验证版本与核心流程。
7. Release、插件 ZIP、网页 ZIP、运行目录和 Pages 来自同一提交。
