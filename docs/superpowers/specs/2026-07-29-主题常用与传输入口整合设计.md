# 主题常用、旧图文字兼容与传输入口整合设计

## 目标

本批次解决三个相互独立但共同影响双端一致性的事项：

1. 主题面板将“基础”改造成用户收藏驱动的“常用”，原基础主题并入“经典”最前面。
2. 旧导图中的中心主题富文本与新导图采用同一套测量规则，打开后文字完整显示。
3. 网页版删除重复的“导入、导出、备份、恢复”快捷按钮，把完整备份与恢复能力合并到编辑器顶部“导出 / 导入”入口；思源插件使用同一套分组说明。
4. 导图与大纲右键菜单增加可连续插入的持久符号选择器。

## 主题信息结构

### 分组

- `常用`：动态分组，仅展示用户收藏的主题。
- `缤纷`：保留现有主题及顺序。
- `经典`：先展示原“基础”主题，再展示原“经典”主题。
- 原主题 ID、颜色定义和导图中已保存的主题值保持不变。

### 收藏

- 每张主题卡右上角提供一个收藏按钮。
- 未收藏显示空心星标，已收藏显示实心星标，并提供明确的 `aria-label`。
- 点击收藏只改变收藏状态，不预览或应用主题，也不关闭面板。
- 收藏 ID 写入共享 `YeMindSettings.favoriteThemeIds`，网页版和思源插件使用相同的数据结构。
- 设置加载时过滤未知 ID、去重并保留顺序；主题升级或删除后不会产生无效卡片。
- “常用”为空时展示说明：“还没有常用主题，点击主题卡片右上角的星标收藏。”

## 旧导图中心主题兼容

- 旧富文本常见形式为 `<p><span>文字</span></p>`，新数据常见形式为 `<p>文字</p>`。
- 不删除 `customTextWidth`，因为它可能是用户主动拖动设置的宽度。
- 渲染与测量必须以可见文本的真实边界为准；冗余内联标签不能改变节点的自动尺寸。
- 兼容处理是幂等的：重复打开、切换主题、保存和重载不会不断扩大节点。
- 验收样例至少包含 `G1架构总览`、`中心主题`、中英文混合文本和用户自定义宽度节点。

## 导入、导出、备份和恢复

### 网页外壳

- 删除网页导图库区域的“导入、导出、备份、恢复”四个重复快捷按钮。
- 保留编辑器顶部“导入 / 导出”作为唯一文件传输入口。

### 导出面板

- 增加清晰的“完整备份”分组。
- 网页版提供完整站点备份，包含导图、设置和检查点，文件名保持可识别。
- `.yemind.zip` 与 `.yemind.svg` 标明为可恢复的导图备份格式。
- SVG、PNG、PDF、HTML、Markdown 等归入“分享与发布”或“文字与大纲”，不能暗示它们都能完整恢复全站数据。

### 导入面板

- 增加“恢复备份”说明与入口。
- 网页版完整站点备份恢复必须二次确认，并明确会替换当前网页版导图库、设置和检查点。
- `.yemind.zip / .yemind.svg` 恢复为新的导图副本，不覆盖当前导图。
- XMind、Markdown、OPML、TXT、MM 等归入“从其他格式导入”。
- 思源插件不提供全站网页备份，但使用相同的“恢复备份 / 从其他格式导入”术语和格式说明。

## 失败与边界

- 收藏设置保存失败时回滚 UI，并显示错误提示。
- 导入未知或损坏的备份不得改写现有数据。
- 完整恢复必须保持事务性：三类数据校验全部通过后才写入。
- 只读模式下允许查看主题和收藏状态，但不能应用主题；收藏属于用户偏好，仍允许修改。
- 所有弹层继续满足屏幕边缘约束、点击空白关闭和关闭按钮关闭。

## 符号选择器

- “添加”子菜单中以 `Ω` 为图标显示“符号”，位于“图标”上方。
- 分类包含箭头、形状、数字、括号、汉字结构、数学，数据来自用户提供的 ChatDraft 符号表。
- 点击对话框外不关闭，只有标题栏“关闭符号”按钮关闭。
- 对话框可拖动并限制在编辑器范围内；支持搜索和连续插入。
- 富文本正在编辑时插入当前光标并替换选区；其他状态追加到当前节点文字末尾。
- 导图和大纲共用同一对话框与插入命令，切换节点后继续向新节点插入。

## 验收

- 单元测试覆盖主题分组顺序、收藏增删/持久化/去重、旧富文本几何、重复入口删除、备份与恢复路由。
- 浏览器真实操作覆盖收藏后进入“常用”、取消收藏立即消失、旧图中心文字完整、顶部导入/导出可访问备份与恢复。
- 思源运行目录同步后复测同一主题面板、旧图和导入/导出术语。
