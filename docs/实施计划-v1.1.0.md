# YeMind v1.1.0 实施计划

## 1. 布局元数据与兼容层

- 修改 `src/core/layoutPresets.ts` 和 `src/core/layoutAssetPresets.ts`。
- 新增 28 个预设的实际布局标识、根出口、普通节点出口、同级轴和兼容映射。
- 调整 `src/data/layout-catalog.local.json` 的首组顺序。
- 测试预设数量、顺序、唯一布局标识和旧文档回退。

## 2. 派生布局与专用布局

- 新增 YeMind 布局基类和路径变换工具。
- 为左右、上下镜像的树状图、组织结构图和时间轴注册派生布局。
- 为上下双向组织图、双向平衡向下、树形表格、环形图和气泡图实现专用几何。
- 保留鱼骨图现有镜像实现并接入统一元数据。
- 为所有布局补节点边界和连线路径测试。

## 3. 节点快捷控件与拖拽

- 修改 `src/editor/nodeQuickActions.ts`，从统一布局元数据解析根、中间、折叠和叶子节点方向。
- 修改 `src/core/officialDragIntent.ts`，让新布局参与生长方向、同级轴和插入指示线计算。
- 布局切换时清除快捷控件方向缓存。
- 扩展拖拽与快捷控件测试矩阵到 28 个预设。

## 4. 预览与结构面板

- 更新布局缩略图，使实际结构和图标一致。
- 验证结构面板首组顺序为“右、左、思维、逆向、双向平衡向下”。
- 浏览器生成结构面板和 28 个实际布局的总览截图。

## 5. 大纲紧凑布局与六点手柄

- 修改 `src/styles/index.css` 的大纲水平内边距和拖动列宽度。
- 修改 `src/editor/StructuredOutlineEditorController.ts` 的拖动手柄结构和可访问名称。
- 用六个圆点表示拖动区域，悬停和拖动时增强。
- 更新缩进线和放置指示线几何测试。

## 6. 媒体选中与资源操作

- 在大纲控制器中增加图片/剪贴图选中状态、八点装饰、右上角删除和键盘删除。
- 在 `YeMindEditor.ts` 中提供按 UID 删除图片或剪贴图的回调。
- 抽取统一的替换、删除 SVG 图标，供导图图片工具栏和资源操作浮层使用。
- 保留单击、双击和替换浮层的事件仲裁。
- 补只读、失焦、Escape、删除失败和 DOM 重绘后的状态测试。

## 7. 版本、构建与发布

- 将 `package.json`、`plugin.json`、`VERSION`、资产目录和版本文档更新到 `1.1.0`。
- 执行类型检查、全量测试、离线测试、插件构建、网页构建和资源校验。
- 在本地思源运行目录执行同步并检查最小发布清单。
- 浏览器验证插件版和 GitHub Pages 网页版。
- 提交、推送 GitHub 并发布 `v1.1.0` 标签。
