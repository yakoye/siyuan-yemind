## 命名规则与迁移审计

- 稳定规范：`docs/standards/主题.md`
- 历史记录：`YYYY-MM-DD-HHmm-版本-主题-文档类型.ext`
- 时区：`Asia/Shanghai`
- 时间来源优先级：Git 首次加入时间、文件创建时间、文件修改时间、迁移执行时间
- [完整旧路径到新路径迁移清单](document-migration-map.json)

文档检查必须保证历史文件命名有效、迁移旧路径无残留、本地链接不存在断链。文档迁移只调整路径和链接，不改变历史结论、测试数量、哈希或验收结果。
