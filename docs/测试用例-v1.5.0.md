# YeMind v1.5.0 测试用例

## 1. 自动门禁

| 层级 | 命令 | 验证重点 |
|---|---|---|
| 版本 | `npm run check:version` | 8 个版本标记一致 |
| 结构 | `npm run test:structure` | 测试清单、领域入口、孤立文件 |
| 类型 | `npm run check` | TypeScript 和共享接口 |
| 核心 | `npm test` | 命令、布局、拖动、大纲、富文本、主题、存储、传输 |
| 网页 | `npm run test:web` | IndexedDB、宿主适配、菜单、文件传输 |
| 离线 | `npm run test:offline` | 构建后真实运行时冒烟 |
| 资源 | `npm run verify:assets` | 图标、剪贴图、标号和 28 个结构缩略图 |
| 浏览器 | `npm run test:e2e` | Chromium 桌面/移动交互 |
| 发布 | `npm run release:build && npm run release:verify` | 双 ZIP、清单、结构和 SHA-256 |

## 2. 导图

- 根/中间/叶子节点分别执行新增下级、新增同级、编辑、删除当前、删除子树、撤销和重做。
- 28 种结构逐一验证渲染、转换、适配、选择保留和 `+ / − / 数字` 出口方向。
- 节点在同父级、跨父级和跨根分支执行 BEFORE、AFTER、CHILD 拖动；验证 UID、资源和元数据不丢。
- 插入标号、图标、剪贴图、图片、待办、标签、链接、备注、批注、代码、公式；检查文字与资源对齐。
- 单击图片检查八点缩放与替换/删除；双击检查放大、缩放、Esc 和关闭。
- 关联线检查创建、选中、控制点、箭头、文字编辑、删除和撤销。

## 3. 大纲

- 搜索普通文本和富文本；展开/折叠全部；显示节点总数和最大层级。
- 单击同步选择，双击编辑；验证 Enter、Shift+Enter、Tab、Shift+Tab。
- gutter 附近显示六点手柄，离开隐藏；拖动不抢文字选择。
- 图片/剪贴图复用导图资源操作和放大预览。
- 全屏与侧栏互切，拖动宽度限制在 220px 至编辑区 70%，刷新后恢复。

## 4. 富文本

- 导图和大纲分别选中文字，连续点击粗体、斜体、下划线、删除线、颜色、背景、字号和对齐。
- 打开链接、行内链接、代码块和公式对话框，确认选区恢复且按钮真实写入。
- 使用模糊/挖空后撤销和清除；富文本测量不得造成文字漂移。
- 工具栏在四个屏幕边缘、浅色/深色及窄屏下不越界。

## 5. 卡片与复习

- 从真实选中节点创建卡片；刷新后 UID、正反面和状态仍存在。
- 搜索正面/背面/来源；分别筛选全部、收藏、新卡片、学习中、已掌握。
- 翻面、收藏、编辑、状态切换、删除、侧栏/全屏均可用。
- “再来一次”进入本轮队尾；“有点难”和“掌握了”更新到期时间、次数和状态。
- 中途退出再进入，已保存进度不丢；模拟保存失败显示错误。

## 6. 导入导出

- 导入 `.yemind/.kmindz/.svg/.png/.zip/.xmind/.kmind/.json/.md/.opml/.txt/.mm`。
- 验证空文件、损坏 JSON/XML、普通 PNG/SVG、超过 100MB 和未知格式不会替换当前导图。
- 逐一导出全部格式，检查文件名、MIME、非空字节和可重新导入格式的往返一致性。
- 验证旧 `.yemindz.svg/.yemindz.zip` 仍可导入，新 ZIP 使用 `.yemind.zip`。
- 分别打开大纲 HTML 和交互导图 HTML；交互版检查折叠、展开、缩放和适配。

## 7. 界面与宿主

- 浅色、深色、跟随系统/思源分别检查画布、节点、菜单、面板、卡片和对话框。
- 主题卡单击必须立即预览到画布；单击“应用主题”才持久化，直接关闭面板必须恢复已保存主题。
- “经典”九张主题卡逐一检查六个色块，并确认实际一至六号分支按相同顺序着色。
- “彩虹连线配色”使用启用、分隔线、当前配色、渐变预览和下拉箭头组成的单行控件；选择配色后自动启用并持久化。
- 线型逐项检查曲线、直线、折线、圆角；折线必须使用直角拐点，圆角必须具有可见圆角，关闭并重开样式面板后保持选择。
- 深色下打开主题、彩虹连线、搜索/替换、大纲、卡片和复习，检查输入框、按钮、正文、悬停和选中态对比度。
- 1440px、1024px、768px、390px 下检查顶部“更多”、底栏、侧栏和弹窗。
- 关闭固定后，等待三边隐藏；从顶部、左侧、底部任一提示进入都显示三条工具栏。
- 网页版执行新建、重命名、保存、备份、恢复、分享和长按右键；插件版检查 Dock、标签页和关闭前保存。

## 8. 验收记录要求

每次发布记录提交 SHA、版本、运行目录、自动测试数量、浏览器视口、构建产物哈希、Pages URL、Release URL 和已知限制。任何失败项必须先修复或明确阻断发布。

## 10. 图片选择层稳定性回归

- 选中图片后连续拖动画布，图片和八点框不得分离。
- 选中图片后缩小窗口、恢复全屏、切换大纲分栏，选择框应继续贴合真实图片矩形。
- SVG 库坐标与浏览器实际绘制坐标不一致时，以 `<image>.getBoundingClientRect()` 为准。
- 思源未派发窗口或布局事件时，选中态仍应逐帧跟随；取消选择、删除图片、销毁编辑器后立即停止跟随。
- 在大纲分栏中，画布图片仍可选中；双击大纲图片进入统一遮罩式预览。

## 11. 真实文件导入样本

除内存编解码测试外，发布前使用真实文件选择器导入：

- 当前格式：`.yemind.svg/.yemind.zip/.kmindz/.xmind/.png`。
- 大纲格式：`.md/.opml/.txt/.mm`。
- 旧格式：`.kmind/.json`。
- 普通纯 SVG 必须显示“没有可恢复的导图数据”并保持当前导图不变。

固定旧格式样本存放在 `tests/fixtures/transfer/`，不得依赖用户私人文件。

## 12. 大纲待办提示回归

- 未完成和已完成待办在导图、大纲中都使用 17px 紧凑方块；大纲不得再显示“已完成/未完成”大尺寸悬浮卡片。
- 大纲待办按钮的 `title`、`aria-label` 分别为“待办未完成”和“待办已完成”，鼠标悬停 900ms 后仍不得生成通用节点预览浮层。
- 单击大纲待办必须即时切换状态并同步导图；提示不得覆盖当前行文字、上下级节点或分支导线。

## 13. 外壳、搜索与编辑几何回归

- 首次打开编辑器时导航缩略图默认隐藏；单击底栏“显示缩略图”后才创建并显示缩略图内容，再次单击可关闭。
- “已保存”保持普通透明按钮，不使用绿色实心背景；浅色、深色、悬停和键盘聚焦状态均须清晰。
- 左上角品牌必须加载 `assets/yemind-icon-32.png`，并通过 `srcset` 提供 64px、128px 清晰资源；插件和网页版不得使用临时绘制图标。
- 搜索/替换面板使用紧凑双行布局，展开按钮保留统一 SVG 图标并旋转；输入框不得出现浏览器原生黑边，窄屏不得溢出画布。
- 搜索实际功能逐项验证普通文本、区分大小写、全字匹配、正则表达式、选中节点范围、上一个、下一个、替换当前、全部替换和非法正则提示。
- 连续执行“替换当前→全部替换”时，全部替换必须基于最新节点和最新搜索结果执行，不得因异步重绘而漏替换。
- 带待办、图标、标号的节点进入文本编辑时，编辑框必须为左侧附件预留空间；附件、文字、`+ / − / 数字` 不得互相遮挡。
- 根节点完成编辑后必须在当前渲染周期刷新最终文本尺寸，长文本、粗体和缩放状态下不得裁切末尾字符。
- 大纲彩色三角中心与同级分支线使用同一横坐标，所有层级线宽一致；叶子与非叶子节点之间不得出现少线、断线或 1px 偏移。
