# YeMind v1.2.0 多格式导入导出设计

## 目标

思源插件版与独立网页版共用同一套导入导出能力。导出的 YeMind 专用文件必须能完整恢复导图结构、布局、主题、线型、整图样式、节点扩展字段和视图数据；通用格式以跨软件交换和阅读为主。

## 导出格式

界面固定按以下顺序显示：

1. `.yemind.svg`：默认格式。标准 SVG 预览图中内嵌完整 YeMind 单图 JSON，可被 YeMind 再次导入。
2. `.yemindz.svg`：标准 SVG 预览图中内嵌 YeMind ZIP 包。
3. `.svg`：普通 SVG，不内嵌 YeMind 数据。
4. `.kmindz`：采用 KMindZ 的“SVG 外壳 + 内嵌包”形式，包内保留 YeMind 完整数据。
5. `.yemindz.zip`：原始 YeMind ZIP 包。
6. `.md`：Markdown 层级标题。
7. `.opml`：OPML 2.0 大纲。
8. `.xmind`：XMind ZIP 文档。
9. `.png`：标准 PNG，图片尾部附带 YeMind ZIP 包；普通图片软件仍可打开，YeMind 可恢复导图。
10. `.txt`：缩进文本大纲。
11. `.html`：可独立打开的 HTML 大纲，并内嵌 YeMind JSON。
12. `.pdf`：按当前导图画布输出单页 PDF。

## YeMind 包契约

ZIP 根目录包含：

- `manifest.json`
  - `product`: 固定为 `YeMind`
  - `format`: 固定为 `yemind-package`
  - `version`: 当前为 `1`
  - `appVersion`: 生成文件的 YeMind 版本
  - `createdAt`: ISO 时间
  - `mapPath`: 固定为 `map.json`
- `map.json`
  - `product`: `YeMind`
  - `format`: `yemind-map`
  - `version`: `1`
  - `map`: `YeMindMapDocument`

SVG 使用 `<metadata id="yemind-document">` 保存 Base64 JSON，使用 `<metadata id="yemind-package">` 保存 Base64 ZIP。PNG 在 IEND 后追加 ASCII 标记、长度和 ZIP 字节，不破坏 PNG 解码。

## 导入识别顺序

读取文件后不只依赖扩展名，按内容优先识别：

1. PNG 签名，并检查尾部 YeMind/KMindZ 包。
2. ZIP 签名，检查 YeMind manifest、XMind `content.json/content.xml`、KMindZ 内容。
3. SVG/XML，检查 YeMind metadata、内嵌 ZIP、KMindZ 标记；无数据的普通图片 SVG 给出明确错误。
4. JSON，兼容 YeMind 单图、YeMind 备份中的单图、simple-mind-map 根树、旧 `.kmind/.json`。
5. OPML XML。
6. FreeMind `.mm` XML。
7. Markdown。
8. 缩进文本。

支持选择：`*.kmindz/*.svg/*.png/*.zip/*.xmind/*.kmind/*.json/*.yemind/*.md/*.opml/*.txt/*.mm`。其中 `.yemind` 用于兼容旧版网页版单图文件。

## 数据映射

- YeMind 专用格式：无损保留整个 `YeMindMapDocument`。
- XMind：保留节点标题、备注、超链接、标签、图片和层级；不支持的 YeMind 样式回落到默认主题。
- Markdown：`#` 至 `######` 表示层级，超过六级使用缩进列表；导入同时接受标题和列表。
- OPML/MM：递归读取 `outline/topic/node`，标题优先使用 `text`、`title` 或 `TEXT`。
- TXT：制表符或空格缩进构造层级。
- HTML/PDF/SVG：主要用于阅读和展示；只有带 YeMind metadata/包的文件可恢复完整导图。

## 界面与错误

- 编辑器顶栏增加“导入”和“导出”入口，思源版与网页版一致。
- 导出弹层显示格式名称、扩展名和用途，默认聚焦 `.yemind.svg`。
- 导入使用一个文件选择器自动识别格式，不要求用户先选类型。
- 解析失败不写入仓库；错误消息区分“不支持的普通图片”“压缩包损坏”“文件结构无根节点”“版本过新”。
- 导入始终创建新导图并生成新 ID，不覆盖现有导图。

## 兼容与安全

- 文件名移除 Windows 非法字符。
- XML/HTML 导出统一转义文本；HTML 中内嵌 JSON 转义 `<`，避免脚本提前闭合。
- 单个导入文件限制为 100 MB；YeMind ZIP 限制入口数量、JSON 解压后大小并拒绝路径穿越名称。
- 导入后通过现有仓库规范化流程补齐布局、主题、线型和项目样式。
