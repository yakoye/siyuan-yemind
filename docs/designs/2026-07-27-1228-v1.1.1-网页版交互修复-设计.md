# YeMind v1.1.1 网页版交互修复设计

## 目标

在不复制业务菜单定义、不改变导图数据格式的前提下，让独立网页版与思源插件共享同一套菜单动作、节点折叠语义和富文本工具栏。

## 设计

- 网页适配器负责菜单外壳：递归渲染 `submenu`、显示当前项与内置图标，并在打开主菜单和子菜单时按浏览器视口重新定位。主菜单过高时只滚动菜单列表。
- 节点 `+ / − / 数字` 快捷操作直接执行 `SET_NODE_EXPAND`，避免全树 `updateData` 替换正在点击的渲染节点。深层和全图折叠仍保留既有树变换语义。
- 字体完成加载后执行一次带来源标记的完整节点重测；测量缓存继续放在现有离屏可见宿主中，保证测量 CSS 与画布一致。
- 公式按钮使用自包含 SVG 路径，插件端和网页端不再依赖宿主是否提供 `#iconMath`。

## 边界与错误处理

- 菜单与视口保留 8px 安全边距；高度不足时提供纵向滚动。
- 只对有持久化子节点的普通节点显示并执行展开操作，概要节点和叶子节点保持原有保护。
- `document.fonts` 不可用时跳过字体就绪修复，不影响插件宿主或旧浏览器启动。
- 所有改动保持现有 `.yemind`、备份和 IndexedDB 数据结构不变。

## 验证

- 单元测试覆盖菜单四边约束、子菜单、实时节点折叠、字体就绪重测和自包含公式图标。
- Chromium 覆盖画布、节点、大纲三类菜单，根/中间节点折叠展开，长中英文节点换行以及选中文字公式图标。
