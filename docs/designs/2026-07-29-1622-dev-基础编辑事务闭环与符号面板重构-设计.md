# YeMind 基础编辑事务闭环与符号面板重构设计

## 背景

本设计延续 `docs/plans/2026-07-29-1317-dev-基础编辑事务与剪贴板重构-实施计划.md`。上一阶段已经把大纲文本事务、结构事务、剪贴板事务分开，但真实操作仍暴露出事务没有完整闭环：

- 画布编辑时静态 SVG 文本层与 Quill 编辑层同时可见，实时重绘后会再次叠加。
- 输入、粘贴和清空后，Quill 尺寸、节点尺寸、选择框和快捷按钮不是同一帧提交。
- 大纲执行撤销后，模型已恢复，但本地脏 DOM 阻止模型重新投影。
- 浏览器剪贴板中的 `StartFragment` / `EndFragment` 注释穿过清洗器，成为正文。
- 大纲反向拖选的终点落在拖动柄、彩虹线或方块区域时，有效文本 Range 丢失。
- 符号目录把空间布局中的空单元过滤掉，界面只能呈现一条连续按钮流。

## 设计目标

1. 一个 UID 在编辑期间只能有一个可见文字来源。
2. 输入、粘贴、清空均在同一个修订事务中完成内容、测量、布局和浮层定位。
3. 文本选择工具栏只在最终有效非折叠选区产生后显示，不出现中间态浮层。
4. 大纲的 Delete、Backspace、Undo、Redo 与普通文本编辑器一致。
5. 外部 HTML 在进入大纲结构解析前移除注释节点、危险元素和边界噪声。
6. 符号窗口复用现有可拖动持久窗口交互，内容改为分组卡片与语义网格。
7. 同一正式版本的累计构建可以通过 Git 提交、脏状态和提交时间辨识。

## 总体方案

采用“统一编辑会话 + 修订式渲染提交 + 模型回投”的方案，不逐项增加 CSS 或计时补丁。

### 1. 画布编辑会话

`YeMindRichText` 持有唯一活动 UID，并在进入编辑时为该 UID 标记 `data-yemind-text-editing`。静态文本内容在编辑会话存续期间隐藏，但节点背景、连线和单线选择框继续显示。

`RenderLifecycleCoordinator` 每次接收输入或粘贴时：

1. 取消旧修订。
2. 从当前 Quill 内容得到统一的纯文本测量值。
3. 重建当前实时节点的文本几何。
4. 执行一次布局和一次 render。
5. 在 render 回调中重新解析活动 UID、更新编辑器几何、恢复“静态文本隐藏”不变量。
6. 刷新快捷按钮与缩略图。

输入和粘贴使用同一提交函数。粘贴可以同步启动事务，但不能绕开会话不变量。空内容使用节点引擎的最小文本尺寸，不保留旧 `minWidth`、`minHeight` 或白色背景。

### 2. 选区状态机

画布双击进入编辑后，Quill 的最终选区是唯一来源。初始化全选和工具栏发布合并到同一个动画帧，不单独发布中间选区。

大纲在 `pointerdown` 时开始选择会话；每次 `selectionchange` 都把浏览器 Range 与所有 `[data-outline-editor]` 求交并裁剪，保存最后一个非折叠文本 Range。即使浏览器终点进入拖动柄、方块或彩虹引导线，Delete/Backspace 也使用该逻辑 Range，而不是事件目标或当前焦点。

### 3. 剪贴板边界

`sanitizeRichHtml()` 负责安全清洗；新增的剪贴板规范化在安全清洗之前和之后都移除 Comment 节点，特别是 `StartFragment` 与 `EndFragment`。实体只解码一次。

结构判定顺序：

1. YeMind 自有大纲标记或真实列表/缩进：结构化粘贴。
2. 单个 HTML 块，即使 `text/plain` 含浏览器软换行：单节点行内粘贴。
3. 多个真实块：多节点粘贴。
4. 无 HTML：按纯文本显式换行和缩进解析。

### 4. 撤销与模型回投

撤销/重做前先提交当前输入事务。命令执行后，以 `data_change` 提供的模型树为唯一真相。

`StructuredOutlineEditorController.syncFromTree()` 增加外部历史同步语义：当来源是 Undo/Redo 时，取消本地计时器、清除 `dirty` 与过期 Range，再强制 patch 当前行内容；普通实时文本输入仍保护正在输入的 DOM，避免光标跳动。

### 5. 符号面板

保留现有 `SymbolPicker` 的持久、可拖动、仅关闭按钮关闭、连续插入行为。目录模型增加：

- `layout`：`spatial`、`number-pad`、`pairs`、`grid`。
- `columns`：明确列数。
- `cells`：保留 `null` 空位。
- `labels`：可选的人类可读名称。

窗口内容区统一 12px 内边距。每个分组是有边框、实体背景的卡片；卡片内部根据布局显示 3×3 方向盘、数字键盘、成对网格或普通网格。窄屏改为单列卡片，不改变插入逻辑。

### 6. 累计构建身份

正式语义版本继续由 `YM-DEC-003` 管理。本批不擅自修改 `1.5.1`。

Vite 两端构建共享一个构建身份解析器：

- `version`：正式版本，例如 `1.5.1`。
- `commit`：短 Git SHA。
- `dirty`：构建时工作树是否有未提交代码。
- `commitTime`：提交时间。
- `display`：例如 `v1.5.1 · 5bc2ef6` 或 `v1.5.1 · 5bc2ef6-dirty`。

“关于 YeMind”、诊断包和网页版品牌区显示同一身份。同步思源运行目录后核对关键文件 SHA-256。

## 影响范围

- 导图画布与节点。
- 大纲。
- 富文本、选区与剪贴板。
- 菜单、弹窗和面板。
- 插件版与网页版适配。
- 数据生命周期与撤销历史。
- 构建、运行目录和发布物。

不改变导图持久化结构、节点 UID、主题 ID、正式版本号或导入导出格式。

## 验收标准

- 连续输入 30 个字符期间无静态文字重影，活动 UID 只有一个可见文本层。
- 粘贴后下一次绘制完成时，编辑器、节点边框和快捷按钮边界同步，误差不超过 2px。
- 清空后没有残留白色长条，空节点保持统一最小尺寸。
- 双击全选后工具栏只出现一次，不先出现孤立选区浮层。
- ChatGPT HTML 注释不进入正文，不出现转义后的 `&amp;lt;!--StartFragment--&amp;gt;`。
- 大纲删除后 Undo、Redo 在导图与大纲同一轮恢复。
- 反向选择终点落在文字左侧、方块、彩虹线和拖动柄四种区域时均可 Delete/Backspace。
- 符号面板有一致内边距、分组卡片和空间网格，连续插入与持久窗口行为不退化。
- 插件与网页显示同一构建身份；正式版本仍为 `1.5.1`，直到用户确认升级。
