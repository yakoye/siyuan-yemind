# YeMind v1.5.0 界面与双端统一设计

## 1. 目标

v1.5.0 是界面和工作流的大版本更新。思源插件与独立网页版继续只维护一套编辑器、命令、数据模型和导入导出代码；宿主差异仅留在存储、文件选择、下载、分享和窗口适配层。

设计基准来自 `Improve Mind Map Design_version47.zip`，正式功能以 `../releases/v1.5.0/2026-07-28-1854-v1.5.0-YeMind-v1.5.0界面对齐勾选清单-设计.txt` 为验收依据。原型中的静态示例不得进入运行数据。

## 2. 视觉与交互

- 页面背景使用浅灰/深黑蓝点阵画布，工具栏和卡片使用分层表面色。
- 主色统一为 `#22c9a0`，选中、焦点、进度和主要动作共用同一语义色。
- 顶部 44px、底部 36px，左侧工具条保持浮动；一个图钉统一控制三边显示。
- 任一边缘提示都能唤回三条工具栏；隐藏后保留可发现标记。
- 顶部顺序固定为“导图、大纲、卡片、复习、结构、主题、样式、搜索、导入、导出、分享、外观、保存”。
- 编辑器按自身宽度响应：先隐藏文字，再将工具动作收进“更多”，窄屏只保留主视图图标。
- 所有按钮保留 `title`、`aria-label`、键盘焦点和禁用态；减少动画设置会关闭非必要过渡。

## 3. 结构、主题与样式

结构目录共 28 项。组织结构组固定为“向下、向上、向右”，不再提供与原型不符的“上下双向”。每项都必须映射到真实引擎布局和方向几何，节点快捷控件、拖动和连线共同使用该几何契约。

主题分为：

- 基础：YeMind 默认、墨枝、质感、极光、晨雾、沙丘。

## 4. 导图与大纲

- 导图和大纲共享 UID、选区、富文本、资源和命令。
- 节点快捷 `+ / − / 数字` 根据布局真实出口定位；数字与减号互斥。
- 大纲侧栏最小 220px、最大编辑区 70%，宽度持久化；支持搜索、全屏、展开/折叠全部、节点总数和最大层级。
- 六点拖动手柄仅在 gutter 附近显示；拖动提供 BEFORE、AFTER、CHILD 三种提示并拒绝非法自嵌套。
- 富文本工具栏执行前恢复选区，确保导图和大纲中的所有按钮连续可用。
- 图片和剪贴图共享八点选中、替换/删除工具和键盘可关闭的放大预览。

## 5. 卡片与复习数据

卡片独立保存在 `YeMindMapDocument.studyCards`，不会修改导图树：

```ts
interface StudyCard {
  id: string;
  nodeUid: string;
  front: string;
  back: string;
  status: 'new' | 'learning' | 'mastered';
  starred: boolean;
  createdAt: number;
  updatedAt: number;
  lastReviewedAt?: number;
  dueAt: number;
  repetitions: number;
  lapses: number;
  intervalDays: number;
  easeFactor: number;
}
```

卡片面板支持侧栏/全屏、进度统计、搜索、收藏和状态筛选、翻面、编辑、状态切换及来源 UID。复习使用三种评价：“再来一次”“有点难”“掌握了”。“再来一次”在本轮队尾重新出现；其他评价更新间隔、到期时间、次数和掌握状态。保存失败显示错误，内存结果不被静默清空。

## 6. 导入导出契约

导入先检查空文件、100MB 大小上限、容器签名和结构；失败不替换当前导图。继续兼容旧 `.yemindz.svg` 和 `.yemindz.zip`。

导出顺序与后缀：

1. 默认 YeMind SVG `.yemind.svg`
2. 完整 SVG 包 `.yemind.svg`
3. SVG `.svg`
4. KMindz `.kmindz`
5. YeMind ZIP `.yemind.zip`
6. Markdown、OPML、XMind、PNG、Text
7. 大纲 HTML 与交互导图 HTML
8. PDF

交互 HTML 自带导图数据、折叠、展开、缩放和适配，不依赖思源或 YeMind 服务端。

## 7. 宿主边界与错误

- 插件宿主：思源存储、标签页、Dock、宿主主题和文件接口。
- 网页宿主：IndexedDB、浏览器文件选择/下载、Web Share、响应式导图库。
- 保存、导入、导出、分享和复习持久化必须报告错误；不得留下半成品或覆盖已保存数据。
- 菜单按可视区域钳制，支持边缘翻转、内部滚动、键盘导航和触摸长按。

## 8. 发布

版本统一为 `1.5.0`。同一已验证提交同时产出插件 ZIP、网页版 ZIP、清单和 SHA-256；运行目录同步、GitHub Pages 和 Release 不能从不同提交构建。
