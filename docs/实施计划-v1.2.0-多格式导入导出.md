# YeMind v1.2.0 多格式导入导出实施计划

## 1. 共享格式层

- 新增格式目录和固定排序、扩展名、MIME、导入 accept 契约。
- 新增 YeMind 单图 JSON、ZIP 包、SVG metadata、PNG 尾部载荷编解码。
- 新增 Markdown、OPML、TXT、HTML、FreeMind 和旧 JSON 编解码。
- 复用 simple-mind-map 的 XMind 新旧格式解析与生成。
- 为签名识别、格式往返、损坏输入和大小限制补单元测试。

## 2. 实时渲染导出

- 注册 `ExportXMind` 与 `ExportPDF` 插件。
- 给 `YeMindEditor` 增加只读的当前文档快照和格式导出方法。
- SVG、PNG、PDF 从当前实时画布生成，避免自动保存延迟导致导出旧数据。
- 在 SVG/PNG 结果中按格式写入 YeMind 恢复载荷。

## 3. 导入落库

- 新增统一 `importMindMapFile(file)`，按魔数和内容自动识别。
- 将结果规范化为 `YeMindMapDocument`，重新生成 ID 和时间。
- 思源版和网页版都使用“创建新导图 + 更新完整数据”的事务顺序；失败时不留下空白导图。

## 4. 界面接入

- 编辑器顶栏加入导入/导出按钮和导出格式面板。
- 通过编辑器回调把导入结果交给宿主仓库，并在导入后打开新图。
- 网页侧边栏复用相同格式面板和文件选择器；备份/恢复继续保留。
- 增加窄屏、深色主题、键盘 Escape 和屏幕边缘定位样式。

## 5. 版本与交付

- 版本由 `1.1.1` 升级到 `1.2.0`，同步 `package.json`、锁文件、`plugin.json`、常量、README 和版本文档。
- 执行 TypeScript、结构检查、全量单测、Web 单测、插件构建、Web 构建、离线冒烟与资产检查。
- 浏览器实际验证默认导出、PNG/SVG 回导、XMind/Markdown/OPML 导入和错误提示。
- 同步到思源运行目录，再次执行运行目录校验。
- 提交并推送 GitHub 分支。
