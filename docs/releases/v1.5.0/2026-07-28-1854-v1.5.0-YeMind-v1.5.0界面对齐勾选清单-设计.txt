总体结论
========

[x] 以 version47 作为 YeMind 新界面的正式视觉和交互基线。
[x] 允许完整采用 version47 的顶部栏、左侧栏、底部栏、侧栏、弹出面板、右键菜单和明暗主题风格。
[x] 保留 YeMind 当前成熟的数据、导图引擎、编辑、拖拽、导入导出和思源集成能力，不用演示代码替换真实业务能力。
[X] 正式实现继续使用当前 TypeScript、CSS、simple-mind-map、Quill 架构，不整体引入原型的 React、Tailwind、MUI 和 Radix 依赖。
[x] 插件版与网页版继续共用同一套核心编辑器和界面代码，仅通过平台适配器处理存储、文件、分享和思源接口差异。
[x] 所有 version47 中只有外观、没有动作的按钮，在正式版中必须接通真实功能；无法接通的按钮不得伪装成可用状态。
[x] 所有当前已有但 version47 未展示的高级能力继续保留，并统一改成 version47 的视觉语言。
[x] version47 中存在的原型缺陷不得照搬，必须按本清单的稳定性规则修正。

二、设计系统与基础视觉
====================

[x] 建立 version47 对应的统一设计变量，不在组件中散落硬编码颜色。
[x] 浅色画布背景使用接近 #eef0f5 的低对比灰白色。
[x] 深色画布背景使用接近 #111318 的深灰黑色。
[x] 主强调色使用 YeMind 绿色 #22c9a0，并统一按钮、选中、进度和提示状态。
[x] 面板、卡片、输入框、边框、悬停、禁用和文字层级分别建立浅色与深色变量。
[x] 全局圆角、阴影、模糊、间距和动画时长与 version47 对齐。
[x] 顶部、底部、左侧工具栏采用轻量悬浮/半透明面板视觉。
[x] 弹出面板采用圆角、边框、背景模糊和分层阴影。
[x] 节点、卡片和菜单的主次文字对比度在浅色与深色下均可读。
[x] 禁用状态既通过颜色又通过鼠标状态和 aria-disabled 表达。
[x] 图标统一使用同一套线性风格，尺寸、描边和按钮盒子对齐。
[x] 采用 version47 的新 YeMind 叶片/节点图标及 32、64、128 像素资源。
[x] 浏览器 favicon、思源 Dock、页签和界面 Logo 使用一致产品图标。
[x] 字体优先采用产品可稳定获得的字体栈；缺少 Plus Jakarta Sans 时无布局跳动。
[x] 所有动画尊重 prefers-reduced-motion。
[x] 颜色不作为状态的唯一提示方式。

6. version47 的节点快捷按钮基于固定 canvasCenter 和右向布局；打开属性栏时会漂入侧栏，正式版必须使用引擎真实节点边界和布局方向。
7. version47 在 390×844 下存在顶部裁切、底栏挤压、导图名称逐字竖排和中心节点不可见；正式版必须通过响应式门禁后才能发布。
8. version47 的结构、主题、样式、导入、导出、分享、保存和多数右键项仍是演示状态；正式版必须接入当前真实命令。
9. 当前 YeMind 已有大量比原型更成熟的内容、拖动、大纲、资源和诊断能力，v1.5.0 的原则是“采用 version47 界面，保留并提升现有功能”。
