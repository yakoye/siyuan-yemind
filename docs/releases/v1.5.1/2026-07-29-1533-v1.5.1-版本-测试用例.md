# YeMind v1.5.1 测试用例

## 基础编辑事务

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| V151-EDIT-01 | 导图节点粘贴长文本并保持光标在末尾 | 实时编辑框、节点外框和 SVG 选择框同步，单次粘贴只提交一个渲染事务 |
| V151-EDIT-02 | 大纲输入文字、空格、数字并清空 | 只提交对应 UID 文本补丁；节点数、缩放和画布中心不变 |
| V151-EDIT-03 | 普通网页段落粘贴到大纲 | 边界空行被清理，软换行不产生额外节点 |
| V151-EDIT-04 | 粘贴明确缩进的多行文本 | 进入结构事务并生成正确层级，已有 UID 与附件不丢失 |
| V151-EDIT-05 | 导图和大纲选中文字后复制 | `text/plain` 与可用的 `text/html` 正确写入剪贴板 |
| V151-EDIT-06 | 工具栏获得焦点后按 Delete/Backspace | 恢复保存选区并删除文字，不误删节点 |
| V151-EDIT-07 | 从右向左快速框选并越过左侧拖动区后删除 | 视觉选区与实际删除范围一致 |

## 富文本与旧数据

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| V151-RICH-01 | 打开含 `ql-align-center`、`ql-indent-*` 的旧图 | 对齐与缩进保留，迁移后仍为富文本 |
| V151-RICH-02 | 打开含列表、引用的旧图 | 列表/引用结构保留，保存重开不降级 |
| V151-RICH-03 | 画布创建挖空，切到大纲取消 | 大纲识别已启用；取消后正文保留且透明文字/背景清除 |
| V151-RICH-04 | 在浅色、深色下选中文字 | 工具栏不透明、无阴影，文字和按钮均清晰 |

## 卡片与网页外观

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| V151-CARD-01 | 无卡片节点打开“添加”菜单 | “添加到卡片”位于待办上方，图标与文字对齐 |
| V151-CARD-02 | 已有卡片节点打开“添加”菜单 | 显示红色“删除卡片”，删除后持久化且菜单恢复创建状态 |
| V151-WEB-01 | 打开网页版桌面与移动布局 | 侧栏、交界处、移动侧栏按钮和浮动控件无大面积重阴影 |

## 发布门禁

执行 `npm run check:version`、`npm run test:structure`、`npm run test:syntax`、`npm run check`、`npm test`、`npm run test:web`、`npm run test:offline`、`npm run verify:assets`、`npm run test:e2e`、`npm run release:build`、`npm run release:verify`。任一失败均阻断发布。
