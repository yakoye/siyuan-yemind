# v1.9.9-rc.3 多标签编辑焦点与节点尺寸验证记录

## 目标

修复思源同时保留多个导图标签页时，当前节点进入编辑状态后 `Ctrl+A`、`Delete`、`Backspace` 可能作用到旧标签页编辑器的问题，并继续交付 rc.2 的首次加载尺寸、root 裁切和大纲编辑后宽度拖动修复。本版本是发布候选版，用户实机确认前不得提升为稳定版。

## Trace 与根因

`Trace-20260803T152224.json.gz` 中当前编辑器已执行 `showEditText`、`focus`、`setSelection` 和 `deleteText`，随后焦点发生切换。思源会让多个导图标签页同时保持挂载；此前每个 `YeMindRichText` 实例各自维护 `ownsEditFocus`，而切换标签并不会结束旧标签页仍打开的 Quill 会话。旧会话因此仍可能保留快捷键和选区，单导图测试无法暴露这个问题。

## 修复

- 文档级编辑焦点只允许一个 `YeMindRichText` 实例持有。
- 新导图开始编辑时，先用上游 `hideEditText()` 完整提交并关闭原编辑会话，再转移所有权；不保留第二套关闭流程。
- 原持有者关闭后不能再响应宿主焦点恢复或截获快捷键。
- 当前编辑器关闭时只释放自己的所有权，不影响之后已接管的编辑器。
- 没有修改 Quill 的选择、删除和剪贴板语义，避免再建立第二套快捷键实现。

## 回归用例

| 用例 | 预期 |
|---|---|
| 两个导图编辑器同时挂载，先编辑 A 再编辑 B | A 的编辑会话先完整关闭，B 成为唯一焦点所有者 |
| 切换后宿主触发 `focusin` | A 不得重新聚焦，B 恢复当前选区 |
| 当前节点多行全选后按 Delete | 一次删除全部选中文字 |
| 当前节点多行全选后按 Backspace | 一次删除全部选中文字 |
| 宿主短暂取得焦点后执行删除 | 保存的真实文本 Range 仍生效 |
| 已有节点全选、删除、重新输入 | 光标和内容留在当前导图 |
| 大纲提交文字后立即回画布拖宽 | 手柄可用，宽度立即变化 |
