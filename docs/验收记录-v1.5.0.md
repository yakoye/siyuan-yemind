## 关键人工结论

- 编辑器宽度而不是浏览器总宽度决定顶部收纳，网页版导图库不会再挤掉右侧操作。
- 结构面板顺序符合清单，组织结构为向下、向上、向右。
- 基础主题为默认、墨枝、质感、极光、晨雾、沙丘；新主题含独立六色浅/深定义。
- 经典九套主题各显示并实际使用六种分支色；“永恒”实机连线与截图六色完全一致。
- 缤纷和经典主题在不改变主题 ID 的前提下生成深色画布及可读节点层级，不再出现深色外壳配白色画布。
- 卡片侧栏和全屏模式可读，深色和窄屏下进度、筛选与空状态清晰。
- 菜单和浮层保持在视口内，键盘和触摸长按路径保留。
- 390×844 网页版导图库按钮与“导图”按钮不再重叠，并有浏览器回归断言。
- 思源必须冷启动才能清除旧插件模块缓存；普通页面刷新不足以验证新构建。
- 运行目录 `index.js`、`index.css`、`plugin.json`、`VERSION` 与最终本地构建 SHA-256 一致；同步未触碰思源用户地图存储。

## 代码审查闭环

- 插件导入与网页导入都保留 `studyCards`，失败时删除半创建文档。
- 卡片快速连续写入使用串行队列；只读模式在界面和事件入口双重拒绝写入。
- 卡片/复习切换清理图片八点框、资源浮层、富文本工具栏、预览和搜索面板。
- 大纲图片单击打开统一资源操作，双击进入放大预览，不再打开旧图片地址表单。
- 当前筛选卡片作为显式复习队列，不会被“全部到期卡片”覆盖。
- 旧 `organization-bidirectional` 与 `yemindOrganizationBidirectional` 显式迁移为 `organization-right`。
- ZIP 导入在读取条目内容前限制条目数、单项大小、累计解压大小、压缩比和路径。
- 顶部/底部更多菜单支持方向键、Home、End、Esc，且属于自动隐藏交互区域。

## 发布阻断条件

若运行目录同步删除 `data/`、任一自动门禁失败、Pages 与最终提交不一致、Release 缺少任一 ZIP/清单/哈希，或思源实际加载版本不是 1.5.0，则本记录不能标记为最终通过。

## 已知上游依赖事项

`npm audit` 在 2026-07-28 报告 0 个 critical、10 个 high、1 个 moderate、1 个 low。High 主要来自 vendored `simple-mind-map` 将 ESLint/Tern/Glob 工具链列入运行依赖；浏览器代码未调用这些工具路径。UUID 告警涉及带外部 buffer 的 v3/v5/v6，当前仅调用 v4；Quill 2.0.3 的低风险项涉及 HTML 导出。强制修复会跨主版本替换导图引擎工具链，因此不在 v1.5.0 中盲目执行，后续按 `DEVELOPMENT_PLAN.md` 在保持行为兼容的前提下单独升级。
