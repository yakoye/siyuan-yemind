# 主题常用与传输入口整合 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 增加可持久化的常用主题收藏，修复旧富文本中心主题尺寸，并将网页备份/恢复合并到双端统一的导入导出入口。

**Architecture:** 主题静态定义保持原 ID 与分类，新增纯展示映射生成“常用 / 缤纷 / 经典”；收藏 ID 存储在共享设置。旧图兼容通过统一富文本测量规则处理，不破坏用户宽度。文件传输由共享编辑器面板承载，网页版通过宿主回调注入完整备份与恢复能力。

**Tech Stack:** TypeScript、Vitest、Playwright、simple-mind-map、SiYuan Plugin API、IndexedDB/web storage。
