# YeMind v1.7.0 基础编辑、剪贴板与日常操作矩阵实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把导图与大纲中的新建、编辑、复制、剪切、粘贴、删除、拖动、折叠、格式和撤销重做收束为一套可重复验证的事务模型，并让图片、文字、节点在同文件与跨文件间按同一规则工作。

**Architecture:** 新增统一的 `ClipboardCopyIntent` 决策层，只负责根据真实选区、直接右击资源、已选中资源和节点选区决定复制对象；图片二进制/HTML/纯文本写入由独立资源剪贴板服务负责。导图和大纲只提供当前交互快照，不再各自猜测复制语义；节点结构仍使用版本化的 `application/x-yemind-nodes+json` 事务。全部行为先补失败测试，再修改共享 `src/` 实现，网页端和思源插件端不建立平行逻辑。

**Tech Stack:** TypeScript、Quill 2、simple-mind-map、Vitest、Playwright、SiYuan 3.7.3 实机。

## 一、行为契约

### 复制优先级

```ts
export type ClipboardCopyIntent =
  | { kind: 'text' }
  | { kind: 'resource'; resource: ClipboardImageResource }
  | { kind: 'nodes' }
  | { kind: 'none' };

export interface ClipboardCopyContext {
  trigger: 'keyboard' | 'context-menu';
  hasTextSelection: boolean;
  directResource: ClipboardImageResource | null;
  selectedResource: ClipboardImageResource | null;
  hasNodeSelection: boolean;
}
```

判定顺序固定为：

1. 右键直接落在图片或剪贴图上时，复制该资源，不受旧文字选区或节点多选影响。
2. 键盘复制且存在当前编辑器真实文字选区时，复制文字。
3. 键盘复制且存在当前表面选中的图片或剪贴图时，复制该资源。
4. 非编辑态存在节点选区时，复制完整节点结构。
5. 其余情况不拦截浏览器或宿主默认复制。

### 资源剪贴板载荷

- `image/png`：可转换时写入真实位图，供第三方应用直接粘贴。
- `text/html`：写入包含 `img`、`alt` 和来源地址的安全 HTML。
- `text/plain`：写入资源标题；无标题时写入来源地址。
- 图片读取或 PNG 转换失败时仍保留 HTML 与纯文本，并记录诊断；不得退化成复制整个节点。

### 节点剪贴板载荷

- 同文件保留节点视觉样式、富文本语义、图片、剪贴图、图标、待办、备注、批注、标签和链接。
- 跨文件移除整节点视觉样式和源 UID，保留结构、富文本语义与完整内容资源。
- 真实文字复制必须清除上一份共享节点载荷，防止随后粘贴误变成整节点。

## 二、文件职责

- 新建 `src/editor/clipboardCopyIntent.ts`：纯函数决策、资源快照类型、Clipboard API 写入与降级。
- 修改 `src/core/YeMindNodeImgAdjust.ts`：只公开当前画布资源快照和目标命中，不负责菜单。
- 修改 `src/editor/StructuredOutlineEditorController.ts`：公开当前大纲资源快照，复制事件与右键目标均交给统一决策。
- 修改 `src/editor/YeMindEditor.ts`：协调两种表面的复制快照，提供右键与键盘公共动作。
- 修改 `src/ui/contextMenu.ts`：菜单只调用传入的复制动作，不自行推断复制对象。
- 扩展 `tests/suites/commands-selection/`：复制意图、资源写入和节点载荷单元测试。
- 扩展 `tests/suites/outline-split/v094StructuredOutlineEditor.suite.ts`：大纲图片、文字、节点优先级测试。
- 扩展 `tests/e2e/web-node-clipboard.spec.ts`：导图/大纲、编辑态/非编辑态、同文件/跨文件、文字/图片/节点的真实浏览器矩阵。
- 新建本次 `docs/regression-runs/` 发布级执行记录：登记每条用例、命令、截图、实机和发布证据。

## 四、发布阻断条件

- 任一复制意图路由错误：文字变节点、图片变节点、节点变纯文本。
- 右键直接图片与 Ctrl+C 选中图片不能在第三方或另一 YeMind 文件粘贴。
- 跨文件带入源 UID 或整节点视觉样式。
- Delete、Backspace、Ctrl+X、撤销或重做任一核心流程失效。
- 编辑、粘贴、拖宽、节点切换或工具栏出现闪白、重影、坐标漂移或文字与边框不同步。
- 网页端与思源端行为不一致。
- 任一发布级自动门禁、实机验证、哈希或线上验证缺少证据。
