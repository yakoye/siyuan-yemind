# Theme Palette Dropdown Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Change only the existing “主题” dropdown presentation into a grouped palette-card selector where every theme displays exactly six color blocks, while preserving all theme definitions, IDs, categories, selection, persistence, and application behavior.

**Architecture:** Keep `ProjectChoicePanel` as the shared controller for both Theme and Line Style. Add an opt-in `palette` presentation used only by the Theme panel; Line Style remains on the current list presentation. Derive six preview colors from each preset’s existing light appearance branch colors without changing theme data.

**Tech Stack:** TypeScript, DOM APIs, CSS, Vitest contract tests, dependency-free offline smoke tests, Playwright/Chromium smoke validation.
