# YeMind v1.3.0 双端统一与全功能稳定性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在一套共享源码上交付功能一致的思源插件版和独立网页版，完成明暗外观、独立自动隐藏工具栏、可发现的隐藏入口、大纲六点拖动柄、图标语义修正，并用自动化与真实浏览器回归覆盖导图和大纲的核心功能，最终发布 v1.3.0。

**Architecture:** 保留 `src/` 作为领域模型、编辑器、导入导出和共享 UI 的唯一实现，`src/index.ts` 与 `web/src/` 只负责宿主能力适配。外观模式、工具栏可见性和拖动柄显示均由可单测的状态控制器管理；GitHub Actions 使用同一次构建产物同时生成插件包、网页包、校验和与 Pages 站点，避免双端版本或代码漂移。

**Tech Stack:** TypeScript 5.7、Vite 6、Vitest 3、jsdom、simple-mind-map、Playwright、Node.js 22、GitHub Actions、GitHub Pages

---

## 交付约束

- 版本：`1.3.0`，并统一 `package.json`、`package-lock.json`、`plugin.json`、`VERSION`、`web/VERSION`、运行时常量和构建信息。

  - `siyuan-yemind-v1.3.0.zip`
  - `yemind-web-v1.3.0.zip`

- 当前版本不开发“复习与卡片”；仅保证既有挖空/模糊功能不回归。
- 不复制业务实现到 `web/`；双端差异必须通过宿主服务接口或适配器解决。
- 不删除用户数据、不覆盖未知运行目录文件；同步运行目录前先验证目标并生成清单。

- [ ] **Step 3: 实现共享外观类型与纯函数**

```ts
export type AppearanceMode = 'system' | 'light' | 'dark';
export type ResolvedAppearance = 'light' | 'dark';

export function normalizeAppearanceMode(value: unknown): AppearanceMode {
  return value === 'light' || value === 'dark' ? value : 'system';
}

export function resolveAppearance(
  mode: AppearanceMode,
  systemDark: boolean,
): ResolvedAppearance {
  return mode === 'system' ? (systemDark ? 'dark' : 'light') : mode;
}
```
