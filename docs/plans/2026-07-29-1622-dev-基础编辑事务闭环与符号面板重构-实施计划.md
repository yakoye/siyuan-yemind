# YeMind 基础编辑事务闭环与符号面板重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让画布与大纲的输入、粘贴、选择、删除、撤销在一套可靠事务中同步，并把符号窗口重构为现有面板家族的分组卡片布局，同时提供双端统一构建身份。

**Architecture:** `YeMindRichText` 管理唯一活动编辑会话，`RenderLifecycleCoordinator` 原子提交内容与几何，`StructuredOutlineEditorController` 管理逻辑选区和模型回投。剪贴板先清洗注释边界再分类。`SymbolPicker` 保留持久窗口壳层，目录模型负责布局。Vite 共享构建身份解析器。

**Tech Stack:** TypeScript、Quill 2、simple-mind-map、Vitest、Playwright、Vite、CSS

---
